# 三色联合规划与操作

1. 从取色圈外缘拟合小数像素圆心，色板裁切边界仍由色卡布局确定。按区块和独立的目标／替代色容差提取候选，保留整列取色器遮罩。
2. 检查全部启用区域对，从候选组合求共同相似变换 p = A q + b，其中 A = sR。有精准命中时仍保留空间分布的妥协种子，避免精准点之间距离不可达时漏掉其他方案。分别测量放大与缩小档位，禁止用一个方向的倒数替代另一个方向。按实际离散倍率重新采样全部启用区域；先保护所有启用区域的目标色系，再比较精准区域最大、平均色差，最后比较整体最大、平均色差，精准命中数仅作色差相同时的后续排序项。
3. 在色板内选择可完成右键圆弧的整数支点 c。优先减少补偿平移，不固定使用色板中心。
4. 分解为围绕 c 旋转、围绕 c 缩放，最后平移 d = b - (I-A)c。旋转与缩放可用同一支点，并非必须不同；支点改变不会增加整体变换的自由度。
5. 实际右键按下点就是 c，按住径向移动再画圆弧。缩放鼠标置于 c 后逐格滚轮。
6. 发布候选前预估动作路线和三个取色点的收敛。当前预估的旋转仍采用理想请求角度，尚未完成整数轨迹量化与游戏响应的可达性验收，详见 `GESTURE_REACHABILITY_AUDIT_20260929.md`。执行时每次动作后从画面测量变换，更新候选位置，再规划下一步，禁止把未产生图像响应的指令量当作实际量。
7. 初始纯平移与实测姿态下的备用平移均按实际整数鼠标位移重新评分。实际响应偏离校准时，可以保持已可靠测量的旋转、倍率，用本局大图重新计算整数平移方案及其预测颜色。
8. 到位后读取游戏 HEX 复核全部启用区域，分别报告达标或妥协结果。最终套用由游戏界面完成，工具不发送套用输入。

限制：屏幕像素受插值影响；候选图像颜色不是最终色码证明，必须读取游戏实际 HEX。任意三种颜色不一定存在满足共同变换的组合。
