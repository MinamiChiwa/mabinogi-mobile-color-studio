# 三色共同变换与操作

坐标采用游戏客户区物理像素。三个取色点由外圈拟合确定，取色器及其半透明延长部分使用整列遮罩。屏幕固定的材质区域分别建图，纹理共同接受平移、旋转和缩放。

1. 同一颜色板上的源点满足共同相似变换 `p = sR q + b`。三个颜色目标不是独立控制量；有限搜索不能证明所有目标组合均存在可达解。
2. 搜索覆盖全部启用区域对。纯平移在代表性周期单元内直接枚举整数屏幕位移；非整数周期边缘的邻域按实际位置额外采样，不假定整数网格严格周期环绕。
3. 联合颜色种子产生连续几何提案，再绑定整数鼠标轨迹、右键按下支点和整数滚轮档位。规划与输入共用动作描述及节奏。
4. 旋转以右键按下位置为支点，保持按下后径向移动并绘制整数圆弧。预测使用实际圆弧几何角，不使用未经量化的请求角。滚轮放大与缩小分别测量，不能假定互为倒数。
5. 连续提案在允许的几何残差内停止于实际离散终点，包括合法的不移动终点。终点重新采样并生成独立预测，不沿用连续提案的颜色或精准标记。
6. 候选比较与恢复策略见 [现行策略与优化计划](REACHABLE_SEARCH_PLAN.md)。所有启用区域共同参与最大和平均色差评价；邻域风险属于颜色采样指标，不是实机响应保证。
7. 执行逐步测量实际变换。偏离时丢弃失效的剩余路线，并从可信当前姿态重新规划；缺少响应证据时不得假定逆操作能准确返回。
8. 最终使用两帧游戏 HEX 复核颜色，预测姿态与实测姿态分别记录。短期观察失败时区分已知姿态、未知颜色和历史最佳结果，禁止用预测冒充当前实测。

规划终点与最终几何验收的容差为 1 像素；中途 0.65 像素偏离仍作为剩余路线重评触发条件，两者用途不同。角度和缩放的通用响应范围仍未完成验证，小角度硬门槛及分项响应模型是后续工作。

截图插值、拼图平均、像素取整和标记点误差都可能造成预测 HEX 与游戏 HEX 不同。整数轨迹可发送、路线预测可达、颜色预测达标与游戏实测达标是四种不同状态。当前实机与离线验证范围见 [验证报告](VERIFICATION.md)。
