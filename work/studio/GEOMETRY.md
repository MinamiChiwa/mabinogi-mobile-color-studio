# 三色联合规划与操作

1. 按区块和独立的目标／替代色容差提取候选，排除取色圈与引导线遮挡。
2. 从候选组合求共同相似变换 p = A q + b，其中 A = sR。用第三个区域独立检查组合；任一区域超容差不进入联合定位。
3. 在色板内选择可完成右键圆弧的整数支点 c。优先减少补偿平移，不固定使用色板中心。
4. 分解为围绕 c 旋转、围绕 c 缩放，最后平移 d = b - (I-A)c。旋转与缩放可用同一支点，并非必须不同；支点改变不会增加整体变换的自由度。
5. 实际右键按下点就是 c，按住径向移动再画圆弧。缩放鼠标置于 c 后逐格滚轮。
6. 每次动作后从画面测量变换，更新候选位置，再规划下一步，避免把指令量当作实际量。
7. 接近目标后通过游戏三个 HEX 逐点复核；只有全部启用区域通过，才允许确认结果。

限制：屏幕像素受插值影响；候选图像颜色不是最终色码证明，必须读取游戏实际 HEX。任意三种颜色不一定存在满足共同变换的组合。
