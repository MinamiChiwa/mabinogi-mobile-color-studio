# 项目状态与验证范围

更新日期：2026-09-28。当前维护版本：0.3.2。

## 正式功能

程序面向 Windows 上的港澳台服瑪奇Mobile，使用本局大图拼接、颜色候选搜索、旋转/缩放/平移定位及游戏 HEX 复核。最多支持三个独立区域，可混合使用精准与相似模式。

候选首先按精准命中区域数排序；命中数相同时，依次比较所有启用区域的最大色差和平均色差。未找到全部达标的方案时，保留可测量候选并定位最接近的可执行妥协方案。程序不自动点击套用、确认或取消。

六十秒为性能参考，不作为正常流程的强制停止条件。游戏倒计时、F9、失焦、窗口几何变化及无法可靠识别仍会限制或停止输入。

## 0.3.2 维护内容

- 普通动作、图像配准、候选预算和 HEX 复核异常进入安全恢复状态，不再通过全局错误提示强制结束自动染色。
- 游戏原生缩放到达边界时复查当前画面，并在姿态可靠时尝试备用候选；无法可靠确认姿态时停止输入并保留当前画面。
- 恢复状态包含完整色码字段，浮窗可稳定显示部分读取结果；新增状态提示同步覆盖简体中文、繁體中文和 English。
- 保留 F9、失焦、窗口几何变化和游戏倒计时安全截止保护，并确保异常路径释放鼠标。
- 主窗口标题与品牌区域显示版本号 `v0.3.2`。

## 验证证据

- 回归测试 425 项：408 项通过、17 项因本地素材缺失而跳过、0 项失败。
- 布局计算矩阵覆盖 1024×768、1920×1080、3840×2160、5120×2880 及 100%、125%、150%、200%、250% DPI。物理像素、负坐标多屏和三语提示另有测试。
- 自动化几何测试不等同于所有显示器、混合 DPI 或 Windows 语言配置的实机游戏验证。
- 既有游戏记录完成过定位与 HEX 复核，但截图预测仍可能与实际 HEX 不同。0.3.1 不修改颜色模型，也不宣称新的命中率。

完整证据与边界见 [0.3.2 验证报告](RELEASE_VALIDATION_0.3.2.md)。既有维护验证见 [0.3.1 验证报告](RELEASE_VALIDATION_0.3.1.md)，实机数据见 [0.3.0 验证报告](RELEASE_VALIDATION_20260928.md)。早期日期命名的报告保留为历史实验记录，其当时结论不代表当前版本功能状态。
