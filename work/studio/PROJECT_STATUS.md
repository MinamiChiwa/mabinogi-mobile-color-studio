# 项目状态

当前版本：0.3.5。验证依据、实机结果和已知限制统一记录于 [验证报告](VERIFICATION.md)；正式发布文件以发布页附件为准。

现行目标、候选顺序和后续工作以 [现行策略与优化计划](REACHABLE_SEARCH_PLAN.md) 为准；共同变换、输入与坐标约定见 [几何与操作](GEOMETRY.md)。历史实验报告只代表其记录时的实现与条件。

相邻截图特征不足时使用密集特征重试，保留原有匹配与质量门槛。1280×960 游戏窗口下的拼图中断已完成原始截图回放和后续实机流程复核。

当前实现包含本局拼图、整列遮罩、整数动作绑定、实测姿态重规划、双帧 HEX 复核和历史最佳结果保护。候选评价兼顾启用区域和落点邻域变化；精准命中不再无条件压过整体色差。普通扫描已关闭持续早期诊断采样；执行诊断文件异步保存，避免占用返程等待时间。

保存大图的绑定回放分别记录候选中心误差、九点邻域误差与操作成本。最新实机流程完成默认候选定位和游戏 HEX 复核，三个区域的预测对实测残差约为 1.047、0.484、0.360 ΔE76；相对于目标颜色的误差约为 19.35、76.52、18.41，结果仍为妥协方案。较小的预测残差仅说明本次预测与实际位置吻合，不代表目标颜色达标，也不构成旋转、缩放在不同环境中的通用响应保证。

渐进拼图处于离线比较阶段，正式采集仍采用完整的 48 步扫描路线。42/48 步对照用于评估后续优化，不代表生产流程已缩短或已启用边采集边搜索。不同窗口和 DPI 有布局、坐标换算和部分实际游戏记录，但尚不具备所有条件的响应覆盖。分项动作模型、按收益补图和阶段降级机制仍需继续实施。

源码入口为 `run_studio.bat`。自动化检查命令为 `python -m unittest discover -s work/studio -p "test_*.py"`。缺少本机实拍资料的测试会跳过；测试计数须分别报告通过、跳过和失败。
