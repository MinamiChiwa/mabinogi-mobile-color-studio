# 项目状态

当前版本为 0.4.0，策略修订 `native-priority-similar-fine-scale-v15`。默认 native 精准寻色通过只读当前游戏数据恢复本局色板，搜索周期域候选，编译 Windows 鼠标路线，并以实际游戏 HEX 和截图复核。图像 atlas 策略作为故障备用入口保留。

三个区域共享平移、缩放和旋转。精准只接受相同六位 HEX；相似按各区 ΔE 容差。全部启用区域达标永远优先。显式优先级按区域命中顺序，再按同顺序的 ΔE 排序；未设置优先级的旧 API 规则保持旧均衡排序。候选预截断、路线、实测记录、细化与保护返回使用同一质量顺序。

窗口尺寸不再固定为 1280×960。客户端物理坐标、目标进程坐标、Unity Screen 和 viewport 被分别测量；不一致时使用逐像素整数映射，不能猜测乘以 DPI。窗口/进程/会话/输入分支变化、F9、真实截止和失焦保护保留。

当前设置自动保存；命名方案独立保存、编辑、载入和删除。损坏设置保留，用户后续编辑写入前备份；自动保存结果须以实际文件写入为准。三语教程和 README 说明材质色域、多色共享变换、优先级和备用策略。

局部截图解码预算与会话截止分别处理。advisory 倒计时 OCR 不抹掉已读取 HEX；原生补全截图遗漏仍明确标识，不作为独立截图验收。正反滚轮组合按实际非互逆系数完整回放，支持单轮刻度之间的微调；预测候选必须通过完整路线与端点验算才可执行。

开发默认 `python scripts/run_tests.py`，发布 `--suite release`，大搜索矩阵与历史研究用 `--suite research` 或 `--suite full`。分层不限制实际搜索，日志分别记录通过、跳过、失败和错误。源码编译、包内生产模块与构建指纹应核对。

测试与实机证据边界见 [VERIFICATION.md](VERIFICATION.md)；当前发布不保证多色精准成功率、全局最优结果或所有 DPI/游戏版本均实机通过。完整历史研究在 `docs/research`，日志与个人设置只保留本地。
