# 项目状态与验证范围

更新日期：2026-09-28。当前维护版本：0.3.1。

## 正式功能

程序面向 Windows 上的港澳台服瑪奇Mobile，使用本局大图拼接、颜色候选搜索、旋转/缩放/平移定位及游戏 HEX 复核。最多支持三个独立区域，可混合使用精准与相似模式。

候选首先按精准命中区域数排序；命中数相同时，依次比较所有启用区域的最大色差和平均色差。未找到全部达标的方案时，保留可测量候选并定位最接近的可执行妥协方案。程序不自动点击套用、确认或取消。

六十秒为性能参考，不作为正常流程的强制停止条件。游戏倒计时、F9、失焦、窗口几何变化及无法可靠识别仍会限制或停止输入。

## 0.3.1 维护内容

- 修复 Windows 本地编码路径导致的 OCR 启动错误。语言列表以二进制读取，各候选程序分别设置探测超时；OCR 固定使用 eng，临时识别失败不再永久禁用后续帧。
- 启动等待无固定超时；自动激活游戏失败后可手动激活继续识别。正式输入前对临时倒计时识别失败进行有限重试，不使用假定的游戏剩余时间。
- 补齐三语运行状态、候选操作及异常提示。浮窗长内容可滚动，标题和 F9 停止按钮保持可见。
- 根据显示器工作区与 DPI 计算窗口尺寸，修复部分对话框首次显示为 200×200 的问题；屏幕取色使用物理像素映射，并处理负坐标显示器。
- 旧会话清理在后台执行；会话目录使用唯一后缀。数据目录不可写时依次回退到用户本地目录和系统临时目录。
- 三语使用说明与发布说明统一描述正式入口、实际清理规则和已知限制，保留自愿赞助与 AI 辅助开发声明。

## 验证证据

- 回归测试 420 项：403 项通过、17 项因本地素材缺失而跳过、0 项失败。
- 布局计算矩阵覆盖 1024×768、1920×1080、3840×2160、5120×2880 及 100%、125%、150%、200%、250% DPI。物理像素、负坐标多屏和三语提示另有测试。
- 自动化几何测试不等同于所有显示器、混合 DPI 或 Windows 语言配置的实机游戏验证。
- 既有游戏记录完成过定位与 HEX 复核，但截图预测仍可能与实际 HEX 不同。0.3.1 不修改颜色模型，也不宣称新的命中率。

完整证据与边界见 [0.3.1 验证报告](RELEASE_VALIDATION_0.3.1.md)。既有实机数据见 [0.3.0 验证报告](RELEASE_VALIDATION_20260928.md)。早期日期命名的报告保留为历史实验记录，其当时结论不代表当前版本功能状态。
