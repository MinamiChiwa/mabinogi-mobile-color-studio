# 当前寻色策略与后续验证

默认精准寻色从稳定的本局截图/原生 checkpoint 建立绑定，恢复原始色板与取色点，搜索完整有限周期样本及游戏允许的缩放、旋转范围。候选包含模型可达颜色和输入路线，两者必须分别验证；数学目标存在并不自动意味着有限时间内找到可执行路线。

多个区域的最优达标目标是全部启用区域符合各自规则。精准使用完全相同 HEX，相似按独立 ΔE 容差，替代颜色作为等价可接受目标。启用优先级时，未全达标候选依区域命中顺序、同顺序 ΔE、整体误差与执行成本排序。disabled 区域不参与。旧未指定优先级规则保持均衡 minimax 行为。

全局候选编译为平移、右键旋转、整数滚轮。正反滚轮非互逆，组合可细调缩放；每腿受真实 scale clamp、32 notch 上限和路线动作预算约束。每次输入后读取实际姿态，更新后续路线，不因模型残差大小取消整条路线或重新全局搜索。目标与最终妥协必须通过真实 HEX 复核，截图缺失不得伪称独立验证。

细化仅在保留完整试探、恢复和最终复核时间后开始。当前已复核最佳是保护基线。更差或未复核的落点触发已预留的恢复，不为试探耗尽返程时间。F9、未知输入完成、会话与窗口变化不重试输入。

图像寻色备用路径继续采集图像 atlas、生成与验证候选、执行并读取游戏 HEX；其候选生成、预截断、自动选择、记录与回退遵循同样的显式优先级排序。它并非默认 native 路径的精度保证。

后续应积累不同材质、目标组合和显示设备的真实闭环记录。每次验证区分数学预测、条件输入模拟、截图读色和真实游戏结果。已有双黑实机成功不意味着三色必然成功；有限预算未命中也不证明无解。
