# 现行策略与优化计划

2026-10-09 起，后续任务顺序与验收以 [最终实现推进计划](../../docs/superpowers/plans/2026-10-09-final-implementation.md) 为准。本文件保留当前基线策略及历史设计边界，不表示新增机制或渐进流程已上线。每次新增实机验证需单独确认、最多 1 枚染色剂。

## 产品目标

在本局可用时间内，尽早获得各启用区域均接近目标的实测结果；后续改善必须考虑颜色收益、操作不确定性与返回成本。完整地图覆盖、精准命中数量和几何残差是过程指标，不能单独代替最终颜色质量。

精准模式以游戏 HEX 完全一致为达标标准；相似模式使用每区设定的 ΔE76 容差。妥协结果优先兼顾各区接近程度，整体评价相同时优先精准命中，不为一个精准命中无条件牺牲其他区域。

## 当前实现

- 当前 `0.3.6` 是验证中技术候选，正式验收未完成。单区域直接探索当前画板，多个区域仍完成本局扫描后建图搜索。多区域渐进建图已经进入离线对照，尚未接入实时采集；不固定将 48 步改为 42 步。
- 普通扫描不再额外采集两张早期诊断图；原拖动、停留、正式截图与遮罩保持。`--settling-probes` 可显式启用观察实验。
- 平移直接枚举代表性周期单元内的整数位移。联合搜索保留空间分布种子，并在实际离散倍率上评分；输入绑定后重新计算终点颜色。
- 统一比较顺序：全部达标、中心与邻域最大色差的较大值、中心最大/平均色差、精准命中数及精准区误差、连续色系偏离、动作距离与编号。存在邻域采样时，预测的“全部达标”层要求邻域也完整达标。妥协候选同样使用邻域风险；显式缺失或非有限风险按未知处理，不以中心值替代未知风险。
- 当前不引入新的质量等价区间或权重。精准命中仅在前面的整体指标相同后决定顺序。邻域最坏值是保守的采样比较值，不是校准后的成功概率。
- 实测结果按真实颜色和达标状态比较，清除或忽略历史预测的邻域字段。恢复读色的达标状态与是否完成原路线独立记录。
- 同色系与跨色系方案使用同一排序；中心同色系不再提前删除风险较低的跨色系方案。界面保留色系偏离提示。
- 相同颜色组合在实际路线绑定前保留不同操作路线，避免颜色去重提前删掉成本更低或更可达的路径；绑定及终点重评分后再按实际方案选择。
- 规划停在可执行离散终点并重新算色；不因末尾亚像素位移取整为零而拒绝本已在最终几何容差内的结果。
- 已观察结果的自动试探需要前往及返回路线和时间；输入、读色与重新配准共享本次阶段预算，游戏总截止保持独立。
- 动态返程预算在动作执行前使用预计执行后姿态检查返回成本，动作后再以实测姿态复核。首帧倒计时漏读百位（如 `19` 后续读到 `119`）按连续观测纠正初始锚点，不把冲突读数无条件延长为新截止。
- 正式流程由游戏界面手动套用结果。普通识别与定位故障进入恢复状态；F9 释放输入。

### 单区域搜索与收尾

仅启用一个区域时，不进行整板拼图，也不先滚动到最大或最小倍率。精准模式从识别到可操作画板起，以约 60 秒作为主要探索阶段，优先寻找完全相同的游戏 HEX；连续两帧达标立即结束自动操作。未命中时，临近阶段末尾停止扩展，转入已实测最佳妥协样本的定位与复核。相似模式使用所设 ΔE76 容差，连续两帧达标即停止。

探索动作及其复核使用约 60 秒的软阶段预算；定位最佳样本与末次读色使用独立收尾预算，默认最多至软阶段末尾后 6 秒，且始终取真实游戏截止的较早值。每次新动作之前同时检查探索预算与必要返回预算，不能把一次新探索的成本转嫁到收尾阶段。60 秒不是无条件中断期限；收尾阶段不再扩展地图或提出新目标。F9、失焦及窗口变化仍结束相关输入。没有可靠姿态或读色证据时，当前结果和曾测最佳结果必须分别标明，不能声称已恢复。

探索由有限平移和少量滚轮档位组成，不主动旋转。滚轮向上、向下分别通过前后画面的仿射配准测量倍率，检测到不再变化或不能可靠定位时停止该方向，避免反复冲击最大或最小倍率。双方向的测量结果各自适用，不以向上倍率的倒数推定向下倍率。

首先搜索入口倍率附近的相对区间 `[0.85, 1.18]`；没有进一步改善且相应方向有足够成功测量时，最多扩展一次到 `[0.75, 1.33]`。探索仍受约 60 秒阶段和最多 16 次缩放动作约束，不长期停留在极端倍率。入口的绝对倍率未知，因此不能保证从未触及游戏真实极限；未知响应或无法可靠配准时结束该缩放路线。

最佳样本同时记录游戏 HEX、对应画面及当前姿态，并独立保存当前倍率层的最佳实测样本。后续缩放将全局最佳样本位置投影到当前画面，返回优先使用有证据的平移和游戏 HEX 复核。若跨倍率定位后颜色变差，优先改为当前倍率层内已测最佳结果，且必须有返回与复核预算；不盲目发送反向滚轮，也不把“反向相同档数”作为恢复原倍率或原颜色的保证。最终记录区分全局最佳、当前倍率最佳与当前实测，只有双帧复核与颜色对应证据完整时才标记已恢复。新单区域缩放流程仍需独立实机验证；已完成的纯平移单区域测试不代表新策略已验证。

## 尚未完成的设计工作

### 动作模型与候选搜索

建立平移、旋转、向上滚轮、向下滚轮的分项能力与误差范围，按输入协议、尺寸、倍率、方向和支点记录适用条件。有限局部成功样本不等于跨设备保证。现有 `response_profile_verified` 尚无完整的生产晋级机制，因此自动保护性改善对复杂变换仍较保守。

候选的颜色风险、几何可发送性、响应证据、操作成本应分别评价。固定九点共同平移扰动不能完整模拟旋转/倍率误差；后续应把实测误差分布映射到各取色点。

逐批生成候选，延后颜色去重与数量截断，保留颜色、风险及耗时方面各有优势的路线。UI 显示数量不作为内部搜索空间上限。对精准区保留精确颜色分支，同时保留均衡妥协分支。

### 渐进采集与时间调度

在初始可信画面记录当前结果。提前取得两轴周期证据，逐步构建有支持的地图，按目标附近信息和缺失区域决定下一次采集；存在可靠候选时可以转入定位，不必追求全图 100% 覆盖。

采集停止时刻根据搜索、移动、复核、必要返回的预计成本决定。停止扩图后继续完成当前信息下的结果流程，不设置独立的固定总耗时强制退出。

若已到达较好结果，继续扫描也会离开该位置，同样需要评估返回成本。早期保底不代表必须立刻移动，只有存在可靠改善依据时才执行。

### 失败分级与存储

多区域尚未接入独立的局部妥协搜索。普通建图失败、质量门未通过、没有候选或剩余时间不足以定位时，尝试只读双帧当前游戏 HEX 并展示结果；观察预算最多 3.5 秒且服从真实截止，仅两帧一致才标记已复核，不主动发送新鼠标输入。失败状态与读色状态分别记录。F9、失焦、窗口变化及真实截止不触发额外读色或恢复操作。不能把当前色码展示称为已经定位妥协候选，也不能据此声称姿态可靠或最佳结果已恢复。

局部地图可用时不因全局覆盖不足清空全部机会仍属后续设计；周期无法建立时研究屏幕局部搜索。复杂动作响应不可信时使用当前姿态平移。OCR 暂时不可用时允许有预算的重读，未读到的色码明确标为未知。

执行诊断 PNG 和 JSON 已交给有容量上限的后台队列，不阻塞返程；队列饱和可省略诊断图片或诊断条目，核心采集样本不经该队列。截图快照复制与已启动的原生配准调用仍不能保证严格实时中断。扫描阶段的核心存储与配准分离仍待实施。会话清理仅处理带工具标记的目录，保留最近三次记录并暂时保护活动或近期记录，不设默认总容量上限。

## 验收顺序

1. 真实颜色反例与执行预算测试：不同容差全部达标优先、两个近白优于一白一灰、敏感中心不压过稳定邻域、离散终点重评分、软截止不消耗返程保留。
2. 保存记录配对回放：候选、终点颜色、邻域风险、操作成本、42/48 步地图与相同全局姿态比较。离线资料不改变用户原始会话。
3. 独立实机验证：单/双/三区、精准与相似混合、无彩色及饱和色、不同游戏窗口和 DPI。报告失败场景，不以单次好结果宣称稳定。
4. 发布前核对：最终各区误差、达标比例、首次可用结果时间、历史最佳保留情况、预测残差和失败去向；同步三语文案与程序构建指纹。

当前版本的验证结果统一记录于 [验证报告](VERIFICATION.md)。几何模拟、同一模型生成的输入回放、全局图像门槛和单元测试数量均不代替游戏 HEX 验收。有限时间搜索不保证全局最优或任意目标同时达标。
