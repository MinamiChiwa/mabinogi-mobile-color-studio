## 候选列表问题及修订

事件记录中，初始自动方案为 id=0，列表顺序为 0、6、7 等。方案 0 重规划后的预测为
#9369A7 / #7E5F9D / #304592。它实测偏离色系，随后自动执行备用 id=6。
最后方案 6 的预测已正确更新为表中值，但列表仍以方案 0 为第一行，只有按钮文字标识当前方案。
顶部实测摘要与第一行色块因此表示不同方案；列表内的色块也仍显示预测，而非当前游戏实测。

源码修订为：

- 当前正在执行或完成的方案置于列表首位；复核完成后首行色块、HEX、色差和达标状态采用真实游戏结果。
- 标明“当前方案 · 游戏实测”；未执行选项标明“候选方案 · 预测颜色”。三语内容同步补齐。
- 保留发布时每个候选按钮对应的预测目标。离开曾重规划的候选后，其按钮继续显示原执行目标的预测，
  避免以另一个备用落点的实测色冒充该按钮下次会到达的颜色。
- 展示模型独立保存预测与实测，不改执行目标、候选评分或自动选择规则；新路线生成后清除该行旧实测标记。

该误差不是列表显示造成的。按保存的最终实测姿态重新采样，可完整复现日志预测值，
没有发现最终姿态或备用参考矩阵漏组合导致本次最后结果错误。

在首个落点附近做只读敏感性分析，屏幕位置偏移约 (0.4, 0.3) 像素可找到 #647CB5，

也不能用实际色反向挑选的位置改写预测。未加入通用坐标偏移或更宽误差容限。

## 扫描观察结果

完整流程耗时为 98.178 秒：准备至候选 73.862 秒、首次定位复核 11.930 秒、备用定位复核 12.386 秒。
最终等待选择 20.819 秒另计。48 步扫描段为 55.422 秒。
本局与上一局的目标、显示尺寸和备用次数不同，不能用总时间差直接当作提速收益。
OCR 缓存正常生效：四次读图仅执行两遍 OCR，复用六张完全相同的卡片，累计识别约 1.256 秒。

原拼图质量通过：三块覆盖率 99.4032% / 99.3838% / 99.8569%，
留出覆盖率 96.9598% / 96.0445% / 99.1664%，留出 RGB RMSE 6.1990 / 5.9465 / 3.8586。

48 步均取得早期、检查和正式三张画面；在原材质遮罩内，没有一步三帧完全一致。
所有变化均位于第二区域鼠标拖动经过的局部范围，第一区和第三区逐像素相同。
放大截图可见拖动结束后的亮光及轨迹逐渐消退，正式晚帧中仍有少量残留。
这不支持直接启用当前早期双帧方案，也不能把变化全算成整块色板还在移动。

离线试验按原整数拖动轨迹增加半径 24 像素的静态遮罩后，48 步有效材质像素均一致。
但其覆盖代价较大：晚帧重建的区域 2 覆盖率降至 96.8259%，留出覆盖率降至 90.8623%，
留出 RMSE 为 6.5105。早帧重建为 96.8092% / 90.9241% / 6.5746。
两套虽通过原门槛，但有效数组及周期并非完全一致；特征邻域可能仍受到屏蔽区内内容影响，
不能把材质像素一致等同于整个配准管线一致。

上述扩大遮罩未写入生产。提前采样仍未启用，原先估计的 8–10 秒尚未取得。
后续先研究更局部的轨迹残留排除与配准输入屏蔽，用本局已保存图做对照；
无需为这项分析重新采集相同诊断。覆盖和留出质量不能退化到仅勉强过门槛。
本局首次区域 1 的预测残差与区域 2 的亮光是不同证据，不将后者直接宣称为前者原因。
