# 第五轮：原生截图周期颜色板验证（2026-09-23）

本轮在旧电脑 DESKTOP-IHEHJ8B 上完成一局采集，物理客户区为3839×2049，原点(0,40)。采用用户明确授权的项目本地 Python 截图与输入代码，未采用失效的 Windows.Graphics.Capture 接口。GetDpiForWindow 返回96，只是游戏窗口报告值，不能据此宣称系统缩放为100%。

## 操作与停止状态

纯采集预检每帧约0.11秒。停止事件、F9检测分支、失焦守卫经过模拟检查；不冒充实体F9按键测试。实际退出尝试曾被失焦守卫阻止，未发送鼠标点击。

单局采集约42.09秒：进入准备按钮→识别稳定卡片/取色圈并等待教学→70次单步缩小→基准→8次横向228像素命令→纵向156像素命令→横98/纵58像素命令。窗口几何、原生PNG及操作阶段均记录。上述为输入命令值，图像配准另行测得位移。未进行右键旋转。

最后一张采集图显示87秒。随后尝试取消时游戏失焦，点击未执行。重新读取时已回到时装背包，未观察到退出过程，不能声称程序完成了取消确认，也不能确定由用户退出或超时。程序没有发送“就以此染色”或套用确认。本轮没有自动开启第二局。

## 结果

横向周期约710.475像素，纵向约710.350像素，与旧实验约710像素一致。纵向自匹配搜索范围500–1000像素；横向由接近一周期的累计实测位移减去直接配准残差估计。它们不是源图尺寸，也不证明最小基本周期。
