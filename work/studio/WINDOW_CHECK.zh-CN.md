# 窗口与 DPI 检测

将完整 ColorStudio 文件夹复制到目标电脑，保留 `_internal`。启动游戏，停留普通界面即可，不需要进入染色、不消耗道具。

在此文件夹打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\native-window-check.ps1
```

它只读取目标进程和窗口信息，不发送游戏输入。检测文件保存到 `data/window-check-年月日-时分秒/`，主要查看 `native-preflight.json` 和 `native-preparation.json`。

当前版本支持跨电脑安装路径匹配、高 DPI 客户坐标测量，并将工具进程光标比较作为诊断。预检、截图和鼠标定位都从目标窗口 DPI 上下文测量，再由 Windows 转换到物理像素；当游戏逻辑渲染和物理窗口尺寸不同时，建立实际整数像素映射供搜索和微调使用。截图识别跟随当前色板位置，运行浮窗置顶、不抢焦点、精准寻色期间鼠标穿透，按 F9 或主界面停止。

读取器光标查询与 HWND 坐标转换不一致时，结果写入 `pixel_mapping_diagnostics`，不再先于游戏实际回读停止。记录包含原始坐标、差值和原生鼠标缓存；缓存的“重复读相同”不等于新帧输入证明。进程/窗口变动、真正的坐标表校验失败、F9 和截止时间仍会停止操作。

如果仍提示“窗口坐标映射未完成”，记录里会保存游戏内部尺寸、原始客户坐标、目标窗口上下文尺寸、物理四角，以及 Windows 转换检查的具体失败位置。请提供该检测目录里的两份 JSON，普通界面检测足够，不必开染色局。程序只采用读回核对通过的映射，不用猜测 DPI 倍率操作。
