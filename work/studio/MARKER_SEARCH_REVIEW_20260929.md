# 取色坐标与联合搜索偏差分析

日期：2026-09-29。基线为 0.3.3 之后的未发布工作区。分析使用一份新的有效测试存档和五份外部存档；另一次受弹窗遮挡的采集不纳入精度统计。未发送新的游戏输入。

## 有效测试的失败机制

本次平移已完成，最终配准的三个取色点误差为 0.43–0.45 像素，没有出现此前的缩放中断。第一区域预测为 `#94B4AD`，游戏色码为 `#0DA97D`，预测与实测 ΔE76 为 38.29。误差由两个可复现问题共同产生：

1. 搜索使用浮点平移，而鼠标只能执行整数平移。在实际整数落点重新采样后，预测变为 `#73B09E`，误差仍有 25.92。
2. 旧圆环识别器寻找白色圆周的最高匹配率，多个位置同分时保留最上方位置，未拟合真实外圈。本局第一区域坐标约偏高 1.24 像素，跨越了尖锐颜色边界。独立外圈拟合后，该落点预测为 `#1AA981`，与实际色码的误差约 2.93。

圆心拟合只使用圆环图像几何，不使用目标色、色卡 HEX 或固定坐标偏移。保持原图、原大图和实测姿态，分别更换平移坐标和取色坐标，可区分两项误差来源。

同时，原联合搜索的变换评估数量为零。三个区域分别配置精准白、精准白和精准蓝；前两区的精准种子落在同一小色岛。旧搜索固定只选择这两个区域配对，同岛或相邻周期的间距均不满足已校准倍率范围，其他区域配对没有被尝试。有精准命中的区域也未保留其他位置的妥协种子，导致候选退化为较差的纯平移。

## 代码修订

- 在初次识别时，排除顶部连接杆，以白色外圈的下降边缘拟合亚像素圆心。两个亮度门槛需相互一致，并检查外圈覆盖、半径、残差和修正幅度。白色填满圈内时仍可处理；证据不足时保留原粗定位。场景稳定后复用圆心，避免每帧重复计算。
- 色板裁切边界继续由色卡布局确定，不因圆心小数坐标而移动。遮罩保持原有整列范围，按新几何生成。
- 正式初始平移搜索按整数鼠标位移重新采样，不再显示浮点落点的颜色作为该动作预测。
- 联合搜索检查全部启用区域对。在原精准/近色种子之外，每个区域最多增加 64 个分布于整张周期图的近色种子，避免一个小色岛排除所有妥协路线。
- 在真实离散倍率上分别检查中点补偿及精准区域固定补偿，重新采样所有启用区域。初次回放采用精准命中数优先；后续均衡妥协修订见下节，当前按精准区最大、平均色差优先。
- 原有已测倍率范围、完整路线检查、测量闭环和游戏 HEX 复核保持有效。

## 验证结果与边界

六份存档、每份九张图，共 162 个圆环，独立几何拟合的单坐标跨帧变化不超过约 0.19 像素，外圈拟合最大 RMS 约 0.16 像素。包含 498 和 701 像素宽色板，以及白色和有色圈内填充。

进一步用各局初始截图的圆心、相同原大图和原配准坐标，对六组未参与建图的留出截图读取游戏 HEX。共 108 个点，三个色码未能可靠读取，保留为缺失，不填值；105 个有支持且可读的点得到：

|指标|旧取色坐标|修订后取色坐标|
|---|---:|---:|
|平均预测误差 ΔE76|4.78|2.14|
|最大预测误差 ΔE76|43.60|19.60|
|预测误差超过 8 的点数|20|4|

**仍有四个超限点，修订并非全部精度问题的解决证明。** 其中一个点从 4.40 退化到 8.42；旧最终执行截图还存在 8.12 到 18.06 的退化实例。可见圆心不是游戏内部取样规则的独立证明，截图插值、尖锐色带和点位预测仍有残余误差。这些反例保留在本地分析结果中，不能仅报告改善点。

本局按新几何完整重建，三区覆盖约 99.78% / 99.80% / 99.95%，留出 RGB RMSE 约 6.01 / 5.98 / 3.22，均通过原质量门槛。重建与仅替换搜索坐标的两种回放均找到一个精准白命中、整体最大预测 ΔE76 34.62 的候选，优于旧纯平移的 65.35。未找到所有区域精准命中的候选；该结果不能解释为已经穷举全部可能颜色。

最佳候选采用本局实测倍率 0.802108（向下 22 档），通过完整路线与 40 秒剩余预算的模型检查。模型执行的三个取色点最终偏移约 0.009 像素。该执行模拟使用同源大图和理想动作响应，**只验证路径与坐标组合，不能证明新方案在游戏中的真实颜色**。

回归 443 项：426 通过、17 跳过、无失败。新增覆盖外圈小数坐标、白色圈内填充、不同尺寸、遮挡回退、圆心复用、整数动作重新算色、两精准区无法配对时的妥协，以及其他区域配对不再被排除。

## 精准区域的均衡妥协

另一份完整存档配置为两区精准白色和一区相似蓝色。旧自动落点实测为 `#9EBF9B / #FFFFFF / #5A5A5B`，两个精准白区域的实际色差分别为 34.74 和 0。除了先前的坐标与搜索缺陷，精准命中数绝对优先本身也会排斥零精准命中但两个区域都更接近白色的方案。

现行排序先最小化精准区域的最大色差，再比较精准区域平均色差，然后比较所有启用区域最大、平均色差。命中数仅在上述指标相同时参与排序。全部精准命中的精准区色差为零，因此仍最优；近色方案仍标注为妥协，不视作精准达标。无精准区域时继续按整体最大、平均色差排序，不使用固定的妥协色差阈值。

相同圆心、同一大图、同一搜索空间分别应用旧、新排序，完整重新生成候选，而非仅重排已被截断的旧列表：

|排序|两精准区预测色|精准区最大色差|相似蓝区域预测色差|
|---|---|---:|---:|
|旧命中数优先|`#FFFFFF / #EADEDA`|11.86|34.62|
|新精准区均衡优先|`#FAF8FA / #FFFFFF`|2.69|74.24|

新方案通过 35 秒剩余预算下的完整路线模型检查。精准区域接近程度的改善伴随相似区域的退让，符合精准区域优先的规则；不能将此表解释为所有区域同时改善。两个搜索的离线计算均约 4.0 秒；全部色码均为截图预测，尚未在游戏重新执行。

初始平移、联合搜索内部候选池、最终排序、执行中的平移重搜索，以及有条件的备用候选选择使用相同色差优先级。实测结果补充精准区最大、平均色差，备用策略不再仅凭精准命中数下降排除更均衡的方案。教程与三语说明同步更新。

新增回归覆盖双近白优于白色加绿色、最差精准区优先、全精准命中仍优先、纯相似排序不变、向量化搜索与列表排序一致，以及实测后的备用选择。最终全量回归 448 项：431 通过、17 跳过、无失败。
