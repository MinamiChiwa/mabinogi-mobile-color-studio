# 周期颜色板开发记录

## 已实现（离线原型，尚未替换正式搜索）

- `periodic_atlas.py`：接受两条实测周期向量、参考原点、原生 RGB 帧、分区有效像素遮罩和图像实测位移；按周期相位累积三张独立材质颜色板。保留覆盖计数和颜色离散程度，空洞或冲突像素不进入求解。
- 固定角度、固定倍率下枚举离散平移相位，三个取色点必须共享同一变换。按全区容差达标、最大 ΔE 76、平均 ΔE 76、操作距离排序；相同颜色组合去重。精准模式以 RGB 完全相同为预测达标条件，不把小 ΔE 当精准命中。
- 候选包含三色、逐区色差、最大/平均色差、平移量。截图预测始终标记未复核。
- 浮窗支持候选色块及色差列表、选择回调、批次失效和禁用重复选择。正式 Runner 尚未发送候选事件，也没有连接执行回调；不能把离线结果直接用于输入。

## 离线使用

`python work/studio/atlas_review.py manifest.json output_directory`

manifest 路径相对自身目录解析，格式如下（示例数值，不是本机标定结果）：

```json
{
  "basis": [[710.325, 0], [0, 710.325]],
  "origin": [0, 0],
  "resolution": 256,
  "frames": [{
    "image": "frame.png",
    "masks": ["mask1.png", "mask2.png", "mask3.png"],
    "measured_translation": [0, 0]
  }],
  "markers": [[100, 200], [300, 200], [500, 200]],
  "current_translation": [0, 0],
  "rules": [
    {"enabled": true, "colors": ["#FF0000"], "exact": false, "tolerance": 8},
    {"enabled": true, "colors": ["#00FF00"], "exact": false, "tolerance": 8},
    {"enabled": false, "colors": [], "exact": false, "tolerance": 8}
  ]
}
```

basis 的两列分别为周期向量，translation 为相对参考帧的累计实测位移，不能填鼠标命令量。mask 白色有效，必须排除固定 UI、圆圈、线、鼠标及跨材质边界。所有输入保持同一缩放/角度。输出三张带透明空洞的 PNG、atlas.npz 与 review.json。

`python work/studio/preview_atlas_results.py output_directory/review.json`

用真实浮窗离线审阅候选；点击选择不会操作游戏。

## 下一阶段的门槛

1. 原始截图重新测定横纵周期及相位，不能只把历史纵向 710.325 同时当两个轴的精确值。独立位移/留出帧验证重复和拼接质量。
2. 同倍率、同角度采集重叠帧：优先水平扫描补全每个材质分区，必要时纵移避开 UI 遮罩。停止条件按各区覆盖率及留出验证误差，不能按固定拖动次数。
3. 检验同一相位的各分区 RGB。默认保留三图；只有独立证据确认颜色一致才合并，禁止凭纹理相似合并滤镜。
4. 当前离散分箱会抹平小色岛，不能声称找到全局精确色。增加局部高分辨率采样、插值与取色圆心偏移标定。
5. 扩展缩放/旋转联合候选并限制到实测可执行范围，记录当前变换、候选批次和窗口几何。
6. Runner 状态机改为等待→采集→建图→计算→等待选择→执行→游戏 HEX 复核。计算和等待均响应 F9、失焦、窗口变化和倒计时；为选择与执行预留时间，超时取消而非擅自挑选。
7. 浮窗选择仅提交批次和候选 ID；执行前重新检查画面、会话、几何和剩余时间。每步动作后配准反馈；错误立即释放鼠标。重新计算或状态变化使旧候选失效。
8. 分开展示预测色差与实测色差；未能 OCR 复核要明确显示。自动最终染色不属于这条新流程。

## 新电脑采集协议（1280×960 客户区，100% DPI）

后续实机采集先使用游戏内滚轮逐步放大，而不是把窗口或截图放大。每个滚轮步进后重新识别三张色卡、三个取色点和色板边界；下一步导致识别失败、取色点越界或缩放测量不再变化时，保留上一帧作为最大安全采样倍率。周期、遮罩和有效覆盖率都在该倍率重新测定，不能按低倍率结果直接换算。

达到最大安全倍率后使用二维蛇形扫描。扫描命令按色板宽高约五等分，行间移动纵向步长；每隔固定步数保留一张留出帧，不将其加入训练 atlas。采集提前停止的条件为三个区域均达到覆盖率门槛且留出帧 RGB RMSE 达标；未达标时只补采缺失方向，不发布候选。

候选仍只保存一个周期 atlas。搜索层通过周期相位取模，并在执行半径内展开等价周期位移；候选保留未取模的实际 dx/dy，执行前重新检查当前会话、几何和剩余时间。

## 候选选择与时间预算

“30 秒”是候选计算、默认定位和用户选择后的重定位预算，不是到点直接放弃的截止动作。候选发布后按以下顺序运行：

1. 立即选择当前预测色差最小且可执行的候选，自动移动到该方案并完成一次实测定位反馈。
2. 在剩余时间内显示候选浮窗，用户不选择则保持自动方案，不再重复移动。
3. 用户选择其他候选时，先重新检查会话、几何、候选批次和剩余时间；足够时移动到用户选择方案并读取游戏 HEX。
4. 剩余时间不足以安全完成重定位和双帧 HEX 复核时，不执行该选择，提示用户并保持已到达的自动最佳方案。

候选计算和默认定位必须为选择窗口预留时间。任何超时路径都释放鼠标，不点击确认或套用按钮；“无用户选择”不是错误，也不能触发自动确认。

历史归档不修改。当前未进行第五轮游戏实验，也未取得完整可复用的实机颜色板。
