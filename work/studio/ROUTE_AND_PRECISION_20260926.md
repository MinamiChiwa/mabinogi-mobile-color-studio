# 2026-09-26 纵向路线回放与微移精度审计

## 决策

本轮继续了路线设计和最小往返适配器准备，**没有游戏输入或新的染色局**。
两个方向都得到明确的限制：纵向优先重排未解决减帧配准/颜色质量；
当前微位移配准器也不足以支持 0.035 像素精度验收。
因此不发布新的实机入口、不要求用户重复扫描，也不放宽原质量门槛。

## 1. 纵向优先路线回放

`scan_route_review.py` 按原网格的列位置组织纵向蛇形路线，保留原始行间错位。
参考点仍从第零帧开始；每个变体保留六个原始留出帧，训练颜色与留出颜色分离。
仅使用保留帧重新测量位移与周期，不调用完整轨迹偏移来补全删帧结果。
命令累计位移只约束配准别名，不当作测量位移；留出纹理仍参与几何，须披露这一点。

发现现有 `Game.drag` 将单次 X/Y 位移分别限制在板尺寸的 65%。
498 像素板约 398 像素的纵向跨度必须拆成两次拖动。
本次统计区分了帧数、拖动请求次数和未观测的中间姿态；不能把少拍图直接算作少拖动。

|方案|帧数|拖动请求数|未观测中间姿态|两局重新配准|
|---|---:|---:|---:|---|
|全帧纵向优先|40|39|0|均通过|
|只保留第 0/2/4 行，加原始留出|27|39|13|均失败|
|只保留第 0/2/3/4 行，加原始留出|33|39|7|均失败|
|减列，加原始留出|25|33|9|均失败|

新局减帧首个失败帧对为 16→32 或 6→22；旧局为 2→18，后者出现配准结果与
命令提示不一致。没有用命令替代配准、猜周期别名或让失败继续运行。
此前 7→23 的约 398 像素纵向端点可配准，只是局部证据，不适用于每个纹理位置。

全帧纵向重排的区域 2 最差留出 RMSE 为新局 **8.151**、旧局 **8.365**，门槛为 8，仍不通过。
新局区域 2 六个 marker 都有支持，但最大游戏 HEX ΔE76 约 **32.12**。
旧局区域 1 的六个 marker 仍全部缺少支持，不能因为其余区域误差较低就当作改善。
正式生产路线、atlas 分辨率和门槛均未改变。

这只是保存端点的回放。按新顺序执行的中途画面、实际位移与耗时没有实测，
不得将本次脚本运行秒数当作完整采集时间，也没有据此更新 60.891 秒的旧估算。

证据：`outputs/scan-route-review-20260926/report.json`。

## 2. 当前配准器不支持直接宣称 0.035 像素精度

`micro_registration_review.py` 对保存的前向微移图像做了三项检查：

|检查|结果|能说明什么|
|---|---|---|
|0→1/2/4/8/16 正向、反向独立估计，合成返回原位|最高三点闭合残差 **0.06223 像素**|现有配准结果在部分帧对上的内部一致性已超过原型门槛|
|带 UI 屏蔽与原无屏蔽估计对比|三点差异最高 **0.23448 像素**|结果对特征区域选择敏感；不能指定其中某个结果为真值|
|两张存档图、十二组已知合成小位移|3/12 的最大点误差超过 0.035，最高 **0.10047 像素**|现有图像处理流程在该压力测试中未稳定达到原型门槛|

合成测试使用 OpenCV 三次插值、8 位 RGB，并把屏蔽区 UI 恢复固定。
插值量化和固定 UI 拼接边界可能影响特征，因此这些结果不是游戏引擎的真实移动误差。
不能由此证明微移本身不可逆，也不能据此选择一个更宽的正式容差。

正反闭合只是必要一致性检查；两个方向可以共享同一偏差，闭合接近零仍不能证明绝对精度。
第零帧与自身匹配也不是两个时刻独立截图，不能充当同姿态稳定性验证。
现有资料没有真实返回或独立的同姿态连续帧，这一证据缺口仍在。

证据：`outputs/micro-registration-review-20260926/report.json`。

### 2.1 屏蔽 ECC 对照结果

新增 `registration_precision_methods.py`，将当前 SIFT 仿射、运行时同材质/UI
屏蔽下的全板 ECC 平移，以及按材质区域分别 ECC 后取中位数放在同一审计中。
它只读 `probe_000/001/002/004/008/016`，没有改生产配准器。

在同一批存档帧上，带屏蔽的全板 ECC 正反闭合最大值为 **0.0016–0.0322 像素**；
当前 SIFT 仿射对应最大值为 **0.0564–0.0622 像素**（各帧对不完全相同）。
按材质区域分别 ECC 后，闭合最大值为 **0.0070–0.0224 像素**，但区域位移分歧
在较大位移时达到约 **0.27 像素**，不适合直接当作公共平移。

为了避免挑选最好参数，ECC 的高斯尺度做了 **0.5、0.75、1、1.5、2、3、4** 的扫描：

|sigma|真实存档最大闭合|合成最大 marker 误差|合成超 0.035 的组数|
|---:|---:|---:|---:|
|0.5|0.00996|0.05402|4/6|
|0.75|0.01889|0.04913|2/6|
|1.0|0.01227|0.04287|3/6|
|1.5|0.03215|0.03163|0/6|
|2.0|0.02736|0.02339|0/6|
|3.0|0.01362|0.03005|0/6|
|4.0|0.03320|0.03375|0/6|

这说明 ECC 候选的内部一致性值得继续研究，但尺度敏感性和合成图像的插值/拼接
边界仍未提供游戏真值。闭合偏小也不能排除共享偏差；尚无独立同姿态截图或真实反向动作。
因此 ECC 目前**只作为离线候选诊断，未升级生产，未放宽 0.035 门槛**。

证据：`outputs/registration-method-review-20260926d/report.json`。

在同一台机器、同一批五个正向/反向存档帧对上各重复三次，包含两方向估计，

|方法|参数|中位耗时/五对|备注|
|---|---:|---:|---|

|全板 ECC|sigma 0.5|1.294 秒|五对均成功|

### 2.3 参数扰动下的测量范围

新增 `registration_uncertainty_audit.py`，对同一批五个帧对测试十种诊断变体：
五种 SIFT（匹配比率 0.65/0.70/0.75，RANSAC 误差 1/1.5/2）和五种屏蔽 ECC
（sigma 0.5/1.5/2/4，加一次边缘腐蚀）。这是对参数敏感性的压力测试，不是真实位移标定。
诊断 SIFT 保留不少于 20 内点的拟合以观察参数差异，没有执行生产适配器完整的
40 内点、内点比例、有效采样点数和 RGB 残差验收；下表不能当作生产匹配通过率。

|帧|SIFT 最大闭合/通过数|ECC 最大闭合/通过数|SIFT 平移范围|ECC 平移范围|
|---|---:|---:|---:|---:|
|probe_001|0.0564 / 0/5|0.0331 / 5/5|0.0367|0.0678|
|probe_002|0.0622 / 2/5|0.0406 / 4/5|0.1004|0.0974|
|probe_004|0.0100 / 5/5|0.0088 / 5/5|0.0575|0.0409|
|probe_008|0.0833 / 4/5|0.0227 / 5/5|0.0429|0.0229|
|probe_016|0.0555 / 4/5|0.0332 / 5/5|0.1494|0.0326|

其中“通过数”只表示该变体的正反闭合不超过 0.035；平移范围是五种参数矩阵平移项
在 X/Y 方向的极差所组成的包围框对角线，并非精确的最大两点距离，也不是准确度区间。
SIFT 含缩放与旋转，矩阵平移项与实际 marker 位移必须区分：五个帧对的逐 marker
变化范围最大值为 **0.0253–0.0871 像素**；ECC 是纯平移，两者相同。
合成压力测试的十种变体中，六种请求位移的最大
marker 误差为 **0.0232–0.1005 像素**，每组通过数为 **4/10–10/10**。
这再次说明参数扰动本身足以改变判定，当前没有可据此发布的测量不确定度。

证据：`outputs/registration-uncertainty-20260926b/report.json`。

## 3. 最小往返适配器准备完成，但未接入游戏入口

新增 `micro_return_adapter.py`，只接受已手动识别会话的游戏对象、场景与原始 WorkflowBudget。
没有寻找/点击入口、自动放大、重开、套用、确认或取消行为；没有 UI、CLI 或批处理连接。

- 使用原始共享截止，逐次三色 OCR 同时检查倒计时与界面几何，新的倒计时只能收紧截止。
- 原图与 board crop 按唯一名称保存，OCR 只能读取该适配器本次保存的对象；重复读同一图
  不能冒充两次独立观察。模拟验证中十次观察生成二十张图片。
- 配准矩阵使用板内坐标，三个 marker 明确减去板左上角，避免全客户区坐标混用。
- 每次配准另做反向估计，记录两个矩阵与三点闭合残差；超过 0.035 即停止，
  但即使通过仍标记 `registration_uncertainty_validated=false`、`production_ready=false`。
- `CaptureGame.input_scope` 把诊断 guard 和余量截止绑定到最终 `send` 边界；鼠标移动或
  guard 回调自身耗时越过截止时，也不能继续发滚轮。退出或异常后撤销作用域，不改变原会话截止。
- 只允许八个单刻度、单次运行；失败不自动重试。左右按钮释放分别尝试，即使第一个失败也尝试第二个。
- 日志写入也计入保护，保存结果期间超时或状态变化不能返回“当前已验证”的成功标记。
- 控制器记录与适配器日志均被 atlas 分析器拒绝，避免误当正式建图资料。

只用假游戏和模拟图像运行适配器测试；构造真实游戏对象、真实截图和真实输入均未执行。
输入适配器就绪不代表测量能力就绪，当前不适合让用户开局做正式往返验收。

## 4. 下一步顺序

1. **继续补微位移测量依据。** 带纹理屏蔽的全板 ECC 的闭合较小，但参数扰动仍产生
   0.023–0.097 像素的平移范围；要继续评估局部/密集配准、独立同姿态帧和三点误差，
   不只挑最好方向，也不以相互一致代替真值。原 0.035 容差未放宽，ECC 未接入生产。
2. **跳出简单删帧/重排。** 比较减少重复观察但保留同材质重叠的几何覆盖方案，以及
   是否能用目标候选附近的补充观察减少整板采样成本。后者仍需全局搜索/周期证据和独立颜色验收，
   不能悄悄改成只搜索局部或继续沿用旧局地图。
3. **测量检查具备依据后再准备一次最小人工进入实验。** 首先记录同姿态独立重复帧与三色，
   再决定是否允许首次正反微移；当前不新增入口、不让用户开局。
4. 最后才把经验证的局部反馈接回候选/默认定位/二次选择，实测共同六十秒截止和跨局可靠性。

整体仍为离线工程验证阶段。无损建图优化已保留；颜色质量、真实返回、最大安全倍率、
完整六十秒性能与跨局成功率均未达最终验收。
