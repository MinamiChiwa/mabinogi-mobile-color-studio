# 微移返回验收协议（控制器与适配器模拟已完成，配准精度阻止实机验收）

## 要回答的问题

同一局、相同倍率下，配对滚轮能否让色板离开一个已知三色点，
随后在有限时间内回到该点并复现三个区域的实际 HEX？
当前只有向前路径，不能证明这一点。现阶段不要要求用户开新局执行。
最新配准一致性审计见 `ROUTE_AND_PRECISION_20260926.md`：正反闭合误差最高约 0.062 像素，
合成小位移压力测试也有超过 0.035 像素门槛的结果。不得按现有精度宣称返回验收通过。

## 实现前置条件

- 独立诊断模式；不建整板、不计算正式候选、不调用旧 39 次扫描。
- 手动进入、可靠倒计时识别和复核、F9、失焦、几何变化、输入边界截止全部沿用正式保护。
  全流程 ready+60 与游戏实际截止取较早者；点位诊断另外最多二十五秒。
- 三个 marker 必须在配准矩阵坐标系中；保存完整仿射矩阵与逐点位移，不能只保留平移项。
- 输入前检查预留的移动、双次 OCR、复核预算；时间不足不开始离开基准点。
  不把现有每次五秒/返回三秒/复核四秒的离线初值当已测上界。
- 先补模拟测试：任一滚轮前停止、两半之间停止、反向失败、OCR 稳定但 HEX 不复现、
  累计缩放超三点容差、临界时间只允许释放按钮；失败均不自动重试或重开。

## 最小动作序列

1. 在用户手动进入的同一局中建立安全可见基准 A。两次截图读取三色 HEX，
   点位稳定且文字识别可靠后保存原始图、三色、时间与几何。
2. 只沿 X 方向尝试一次配对滚轮微移，得到 B。记录两半动作各自时间，
   保存图像并测三个点的实际位移、比例变化及稳定 HEX。
3. 交换缩放锚点以请求逆向运动，得到 A′。这是请求，不假定就是 A。
   与 A 直接配准；两次读取 A′ 的三色 HEX，再判断是否复现。
4. 仅在 X 往返已通过且预算足够时，沿 Y 方向尝试一次 B 与返回 A′。
   任一失败立即停止本局诊断，不以多次试探掩盖第一次失败。

每次正反运动最多各一对滚轮；X/Y 两组总计最多八个滚轮刻度。
若需要额外校正，应作为未来独立方案，不能在首次协议中无上限追加。
保护触发时不强行完成滚轮的后一半或返回；只释放按钮，并记录当前状态未验证。

## 通过标准与报告

- 所有启用区域至少三色均通过严格 OCR，A 与 A′ 各两次稳定。
- A′ 的三个 HEX 与 A 逐字相同；仅 ΔE 较小不算返回复现。
- 三个点相对基准的残差均满足原型 0.035 像素条件；
  该阈值尚需可信的配准不确定度支持，单次估计满足不能证明测量精度。
- 记录正向、反向、采集、配准、OCR 和等待的分段耗时；
  全链路计时不能只统计鼠标命令时长。
- 保存每次尝试，包含失败与不支持点；不能仅呈现最好方向。

一次通过只能证明当局当点的返回，不能证明新随机板的成功率、全局最优或任意二维控制。
后续接入正式闭环仍须覆盖另一随机板和实际用户目标，并完成六十秒端到端验收。

## 当前决策

`micro_return_probe.py` 已实现注入式控制器，`test_micro_return_probe.py` 的 24 项测试通过。
逐个滚轮检查保护和双读/返回时间预留，最末输入边界必须由适配器再次检查；
两半之间余量不足即停止，不强行补发输入。上层共享截止与最多二十五秒点位截止取较早者。
返回时直接与原始基准配准，双次 HEX、三点位移均验收；历史基准不等于当前已验证状态。
最多八个滚轮刻度，无重试、额外修正或自动重开。

`micro_return_adapter.py` 现已准备适配器，并只用模拟游戏验证；没有连接 `acquire`、UI、CLI 或批处理入口。
它要求已经手动识别的会话和原始 WorkflowBudget，不自行启动、寻找入口或放大。
已绑定逐帧倒计时复核（只能收紧截止）、焦点/几何/F9 保护、输入最末边界、原图保存、
严格 OCR 和 board-crop 三点坐标。每次配准另外反向估计，闭合残差超过 0.035 像素即停止。
正反一致只是必要检查，不是精度上界；所有结果保留 `registration_uncertainty_validated=false`。
同姿态真实重复测量、带可信真值的精度标定和真实时间上界仍需验证。当前预留不是实测上界。

本协议仍不是用户运行说明。先解决测量精度与扫描预算，再决定最小实机验证时机；
不要因为适配器模拟已完成就让用户开局。整体状态见 `PROGRESS_20260926.md`，
最新证据与后续决策见 `ROUTE_AND_PRECISION_20260926.md`。
