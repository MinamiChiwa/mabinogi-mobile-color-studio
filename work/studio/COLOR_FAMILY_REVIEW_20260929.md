## 修订规则

所有启用区域先比较色系偏离的最大值、平均值；同色系范围内继续比较精准区最大、平均色差，
再比较整体最大、平均色差。禁用区域不参与；多个可选目标以任一符合为准。
实际达标条件仍为相似模式的设置容差、精准模式的 HEX 完全一致。

色系范围是显式产品启发式规则，不是颜色科学标准或游戏精度标定：

- 使用现有 Lab 转换计算色度 C 和环形色相角。
- 目标 C ≤ 12 时按中性色处理：亮度差 ≤ 20，结果 C ≤ max(18, 目标 C + 6)。
- 其余目标：环形色相差 ≤ 35°、亮度差 ≤ 25；结果 C 位于
  max(8, 0.4 × 目标 C) 与 max(目标 C + 20, 1.8 × 目标 C) 之间。
- 超出范围的分量按对应范围归一化，取最大非负超限量作为区域偏离值。
  色度接近零时不使用不稳定的色相角，由色度不足项判定。
- 全部区域偏离为零的候选先于跨色系候选；没有此类候选时仍保留偏离较少的妥协选项，
  并明确标注。本次有界搜索未找到组合不构成色板无解证明。

规则贯通种子选择、联合搜索内部截断、平移搜索、排序、整数路线终点评分、
实测姿态重搜索及游戏 HEX 比较。实测妥协结果的色系若比预测更差，允许在剩余时间内选择更好的候选。
