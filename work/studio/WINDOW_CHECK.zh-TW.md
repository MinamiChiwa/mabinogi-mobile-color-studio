# 視窗與 DPI 預檢

將完整 ColorStudio 資料夾複製到目標電腦，保留 `_internal`。啟動遊戲並停留在普通畫面，無需進入染色，也不消耗道具。

在此資料夾開啟 PowerShell，執行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\native-window-check.ps1
```

腳本只讀取程序與視窗資訊，不傳送遊戲輸入。紀錄儲存於 `data/window-check-年月日-時分秒/`。回報問題時請附 `native-preflight.json` 與 `native-preparation.json`。

預檢支援不同安裝路徑的模組定位，在目標視窗 DPI 上下文中測量，再轉換為實體像素。遊戲渲染與實體視窗尺寸不同時，工具建立並驗證整數像素映射供尋色與微調使用，無需固定遊戲解析度。浮窗置頂且不搶焦點，執行時透傳滑鼠，候選選擇時可點擊。按 F9 或停止可結束流程。

讀取器游標差異作為診斷，不會先於遊戲實際回讀停止。`pixel_mapping_diagnostics` 保留原始座標、差值與原生滑鼠快取觀察；重複讀取相同快取不代表新的輸入影格。程序或視窗變動、映射檢查失敗、F9 與截止時間仍會停止操作。

若座標映射無法完成，紀錄包含遊戲渲染尺寸、原始與目標上下文客戶座標、實體四角及轉換失敗位置。普通畫面預檢即可，不需為蒐集紀錄消耗染色道具。工具只採用驗證通過的映射。

若遊戲程序存取權限遭拒，請讓工具與遊戲使用相同權限層級。遊戲以管理員執行時，退出工具，右鍵 `ColorStudio.exe` 選擇「以系統管理員身分執行」。在普通畫面重試。紀錄包含管理員狀態與完整性層級；查詢受限時明確標示未知。工具不會自動提升權限或改變遊戲保護。
