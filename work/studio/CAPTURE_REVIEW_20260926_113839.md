## 误差来源的离线对照

### 1. 跳过 atlas，直接转移原生训练像素

按实测周期和位移，将留出取色点投影到训练帧，四邻像素必须全部在同材质有效遮罩内；用双线性采样并取多观测中位数。只用于诊断，不发布候选。

第一区域六个点分别有 `2,3,2,3,3,2` 个原生训练观测，确认本局没有原来的点位几何空洞。

但 `grid_030` 第二区域仍有明显误差：

- 游戏 `#946531`；正式 atlas `#9C7A79`，ΔE76 **31.58**。
- 两个原生训练观察转移后的中位预测 `#98777D`，ΔE76 **35.21**。

因此这个异常不能只归因于 atlas 的二次重采样，也不是 OCR 或纯粹缺少观察。

### 2. 图板分辨率与采样格点

保持训练/留出划分、周期、位移、遮罩不变，仅对照 atlas 分辨率和格点原点。“原生格点对齐”将第一格中心对齐参考图片像素坐标 0；805 来自本局最大周期四舍五入，不是手工挑选色码。

|诊断设置|区域 1 / 2 / 3 最差留出 RMSE|18 个点最大 ΔE76|
|---|---|---:|
|正式 768|6.16 / 8.13 / 5.47|31.58|
|768，原生格点对齐|6.14 / 8.04 / 5.42|33.36|
|805，原生格点对齐|4.15 / 4.24 / 3.74|34.12|
|1024|5.21 / 6.68 / 4.79|33.14|

支持图板重采样损失确实影响整板 RMSE，也说明**整板门槛通过不等于取色点 HEX 准确**。805 和 1024 对照均没有解决点位异常，未改为生产设置。对照是在看到基线误差后进行，不能冒称全新独立验收。

### 3. 固定圆心偏移是否足够

第一组 ±1 像素逐点探测使用留出 HEX 选取局部最佳值，只用于识别敏感性，不算通过。部分高梯度点对不到一像素的变化非常敏感。

另做了明确隔离的标定：仅用 **34 张训练帧的色卡 OCR** 拟合每个区域一个固定二维偏移，在 ±1.5 像素内按 0.125 像素步长搜索；训练样本需对所有偏移都有共同有效支持。没有用六张留出 HEX 参与偏移损失。

|区域|参与拟合训练帧|拟合偏移 dx,dy|留出点最大 ΔE76：原始 → 修正|
|---|---:|---|---|
|1|33|−0.750, +0.375|3.92 → 2.30|
|2|29|−0.375, 0.000|31.58 → 22.84|
|3|27|+0.125, +0.500|10.18 → 7.94|

固定圆心修正能改善一部分误差，但不能解释全部误差；不能写死这些本局偏移作为通用补丁。训练 OCR 中无法可靠读取的项保留 null，不猜色；部分帧还因共同支持不足被排除。具体名单和每帧结果记录在 `calibration.json`。几何圆心、游戏内部取样坐标、原生纹理插值和局部颜色变化仍需分开验证。

## 下一步与验收边界

1. 继续使用现有两局资料，比较几何圆心定位、原生训练帧转移和游戏 HEX，建立有训练/验证隔离的点位校准及误差来源检查。尤其不能仅靠整板 RMSE 放行高梯度小色块。
2. 评估原生格点对齐的重采样模型，同时保留点位复核。不得为了使门槛通过而直接升分辨率或放宽 RMSE。
3. 在离线证据和输入保护测试充分后，再设计一局能区分剩余假设的最小采集。需要同时解决最大安全倍率证据不足、较大周期下的采样跨度、约 50 秒扫描耗时；不能盲目增加缩放步数或网格数量。
4. 点位精度可靠后才进入用户目标候选、默认定位、二次选择和完整时间预算的实机验收。之后再做正式入口参数固化、UI 和发布整理。

本轮不需要用户再开启相同采样。错行布局继续保留为采集实验参数，桌面正式默认网格、分辨率、坐标和质量门槛均未变。整体仍处于**本局建图和取色精度校准阶段**，尚不是可以交付的自动染色工具。
