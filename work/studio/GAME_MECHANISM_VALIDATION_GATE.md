# 游戏机制验证边界

自动测试通过说明被测软件契约成立，不等同于真实游戏的通用精准率。发布说明、界面与报告必须区分：保存色板的数学预测、离线输入模拟、实际截图读色、当前会话的真实游戏操作与最终颜色。

当前 0.4.0 保留严格 HEX 与独立容差判断、会话/进程/窗口绑定、完整输入路线回放、真实 checkpoint 以及保护返回。新区域优先级、相似三白细调与界面修订经过离线或自建窗口验证；未新增消耗道具的实机染色局。

窗口尺寸与 DPI 适配有实际 2K 预检、4K/175% 来源记录及整数映射检查。不得据此声称任意显示设备已游戏实机认证。预检通过只代表当前被动坐标与版本检查，不代表染色路线或色码精度。

Exact 只有完全相同六位 HEX 才达标；Similar 使用各区域 ΔE 容差。原生补全 OCR 遗漏不能算独立截图 HEX。妥协和历史最佳不能伪称当前精确结果；未恢复时以游戏当前色码为准。

发布需核对源码指纹、Git 提交、包内模块和资源、当前三语教程与 README、测试计数及实际跳过原因。个人设置、原始会话、游戏实拍、私有截图与机器路径不提交 Git 或发布。用户已授权发布时，无需为这些证据边界重复申请许可，但不能虚报验证结果。
