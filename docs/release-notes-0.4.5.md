# ColorStudio 0.4.5

[简体中文](#简体中文) · [繁體中文](#繁體中文) · [English](#english) · [日本語](#日本語) · [한국어](#한국어)

## 简体中文

相较正式版 0.4.4：

- 加快截图色板拼接，减少重复计算和截图保存等待。
- 精准寻色复用原始采样，临时读取失败或局部超时后重新检查状态并处理收尾。
- 修复停止后长时间等待、旧快捷键事件影响新任务，以及部分窗口色卡识别问题。
- 简化教程、浮窗和五语说明，明确寻色方式、颜色要求及实际结果。
- 关闭旧路径的自动确认、套用和取消，结果由玩家在游戏内决定。

**怎样更新**

- 已安装用户在工具内检查、下载更新，再选择安装并重启；设置、方案与记录保留。
- 首次使用下载 `ColorStudio-v0.4.5-Windows-x64.zip`。无法联网时，在已安装工具内导入 `UPDATE-ONLY-ColorStudio-0.4.5-win-x64.zip`；UPDATE-ONLY 不能用于首次安装。
- 旧更新器遇到安装超时时，按[更新指南](automatic-updates.md)处理。

## 繁體中文

相較正式版 0.4.4：

- 加快截圖色板組裝，減少重複計算及截圖儲存等待。
- 精準尋色重用原始採樣，暫時讀取失敗或局部逾時後重新確認狀態並處理收尾。

- 精簡教學、浮窗及五語說明，區分尋色方式、顏色要求與實際結果。
- 關閉舊流程的自動確認、套用與取消，結果由玩家在遊戲內決定。

**如何更新**

- 已安裝的使用者可在工具內檢查、下載更新，再選擇安裝並重新啟動；設定、方案與紀錄會保留。
- 首次使用下載 `ColorStudio-v0.4.5-Windows-x64.zip`。無法連線時，在已安裝的工具內匯入 `UPDATE-ONLY-ColorStudio-0.4.5-win-x64.zip`；UPDATE-ONLY 不能用於首次安裝。
- 舊更新器安裝逾時時，請依[更新指南](automatic-updates.zh-TW.md)處理。

## English

Changes since the official 0.4.4 release:

- Faster screenshot palette assembly, with less repeated computation and waiting for diagnostic images to save.
- Precise Search reuses original samples and rechecks the state to finish after transient read failures or local timeouts.
- Fixed long waits after stopping, old hotkey events affecting new tasks, and color-card detection in some window layouts.
- Simplified tutorials, overlay messages and five-language guides, separating search methods, matching requirements and actual results.
- Disabled automatic confirmation, application and cancellation in the old workflow. Players decide in the game.

**How to update**

- Existing users can check, download, then install and restart from the app. Settings, presets and records are kept.
- For a first install, use `ColorStudio-v0.4.5-Windows-x64.zip`. If offline, import `UPDATE-ONLY-ColorStudio-0.4.5-win-x64.zip` in an existing installation. UPDATE-ONLY is not a first-install package.
- For installation timeouts with an old updater, follow the [update guide](automatic-updates.en.md).

## 日本語

正式版 0.4.4 からの変更：

- スクリーンショットのパレット構築を高速化し、重複計算と診断画像の保存待ちを減らしました。
- 精密検索で元のサンプルを再利用し、一時的な読み取り失敗や局所的なタイムアウト後は状態を再確認して終了処理を進めます。
- 停止後の長い待機、以前のショートカット通知が新しい処理に影響する問題、一部ウィンドウのカラーカード認識を修正しました。
- チュートリアル・フローティングウィンドウ・5言語の説明を整理し、検索方式、一致条件、実際の結果を区別しました。
- 旧処理の自動確定・適用・取消を無効にしました。結果の使用はゲーム内で決めてください。

**更新方法**

- インストール済みの場合は、ツール内で更新を確認・ダウンロードし、インストールして再起動します。設定・プリセット・履歴は保持されます。
- 初回は `ColorStudio-v0.4.5-Windows-x64.zip` を使ってください。接続できない場合は、インストール済みのツールから `UPDATE-ONLY-ColorStudio-0.4.5-win-x64.zip` を読み込みます。UPDATE-ONLY は初回インストール用ではありません。
- 旧更新プログラムでタイムアウトする場合は、[更新ガイド](automatic-updates.ja.md)をご覧ください。
