# ColorStudio 0.4.7

## 简体中文

- 改善两种寻色方式的妥协配色：按区域优先级兼顾色差、色相和饱和度，减少目标红色却偏向橙色等情况。精准 HEX 与相似颜色的达标条件不变。
- 优化末尾微调和返回纠偏，保护已达标区域，并显示当前试探与已保留配色。
- 修复连续寻色时下方色条停留在上一轮的问题，实时读数与结束后的显示同步更新。

**更新方式**

- 已安装用户：在工具内检查更新，下载后安装并重启；设置、方案与记录会保留。
- 离线更新：导入 `UPDATE-ONLY-ColorStudio-0.4.7-win-x64.zip`，或选用与 0.4.4／0.4.5／0.4.6 安装相符的增量包。基线不符时使用完整离线更新包。
- 首次安装：下载 `ColorStudio-v0.4.7-Windows-x64.zip`。**UPDATE-ONLY 不能用于首次安装或直接运行。** [更新指南](automatic-updates.md)

## 繁體中文

- 改善兩種尋色方式的折衷配色：依區域優先順序兼顧色差、色相與飽和度，減少目標為紅色卻偏向橘色等情況。精準 HEX 與相似顏色的達標條件不變。
- 優化最後微調與返回時的偏差修正，保護已達標區域，並顯示目前試探及已保留配色。
- 修復連續尋色時下方色條停留在上一輪的問題，即時讀數與結束後的顯示會同步更新。

**更新方式**

- 已安裝的使用者：在工具內檢查更新，下載後安裝並重新啟動；設定、方案與紀錄會保留。
- 離線更新：匯入 `UPDATE-ONLY-ColorStudio-0.4.7-win-x64.zip`，或選用與 0.4.4／0.4.5／0.4.6 安裝相符的差異套件。基準版本不符時，請使用完整離線更新套件。
- 首次安裝：下載 `ColorStudio-v0.4.7-Windows-x64.zip`。**UPDATE-ONLY 不能用於首次安裝或直接執行。** [更新指南](automatic-updates.zh-TW.md)

## English

- Improved compromise colors in both search methods. Selection follows region priorities and considers color difference, hue and saturation, reducing cases such as an orange result for a red target. Exact HEX and Similar requirements remain unchanged.
- Improved final adjustments and return corrections to protect regions that already meet their targets. Progress shows the current trial and retained colors separately.
- Fixed color strips showing a previous round's colors during repeated searches. Live readings and final displays now update together.

**How to update**

- Existing users: check for updates in the app, download, then install and restart. Settings, presets and records are kept.
- Offline updates: import `UPDATE-ONLY-ColorStudio-0.4.7-win-x64.zip`, or a delta package matching your 0.4.4, 0.4.5 or 0.4.6 installation. If the baseline does not match, use the full offline update package.
- First install: download `ColorStudio-v0.4.7-Windows-x64.zip`. **UPDATE-ONLY packages are not for first installs and cannot be run directly.** [Update guide](automatic-updates.en.md)

## 日本語

**更新方法**

- インストール済みの場合：ツール内で更新を確認・ダウンロードし、インストールして再起動します。設定・プリセット・履歴は保持されます。

- 初回インストール：`ColorStudio-v0.4.7-Windows-x64.zip` をダウンロードしてください。**UPDATE-ONLY は初回インストール用ではなく、直接実行することもできません。** [更新ガイド](automatic-updates.ja.md)
