# 0.4.3 正式发布计划

用户已授权实现、清理、更新 Git 并发布。以 v0.4.2 为发布说明基线，不新增实机染色或消耗道具。

1. 接入日语、韩语完整界面与 README；五语统一说明台服支持、韩服和日服测试中。保留目标 HEX、快捷键和配置标识，检查动态切换、文本占位符及窄窗布局。
2. 移除发布包中的旧预检 CMD、window-check 脚本和过时入口说明。新增说明放在旧更新器允许的 `_internal/docs` 下；验证 0.4.2 清单解析和更新删除兼容性。
3. 离线完整/差异包统一使用 `UPDATE-ONLY-` 前缀，发布页明确首次安装下载完整便携包，更新包仅用于程序内导入。
4. 根据文件依赖和清理清单移除重复旧程序层与构建副本；保留原始源码、Git、运行环境、必要回放素材、用户数据和最小发布证据，记录实际节省空间。
5. 运行一次发布测试集合及新增语言/更新专项；历史缺失素材如实记录。独立审查后构建正式 0.4.3，核对冻结模块、字体模型、私有数据排除及签名更新资产。
6. 提交代码、推送主分支和版本标签，上传 GitHub draft；核对远端资产与生产验签后发布为 Latest，并保存验证结果。
