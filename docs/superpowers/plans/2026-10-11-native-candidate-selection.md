# 精准寻色候选选择实施计划

用户授权：在已找到目标后继续提供按色差排列的其他候选，时间足够自动定位目标；完善双/三区域和各种匹配策略，并使用简中、繁中、英语。发布暂缓到这项功能和已有修复完成验证之后。

采用现有原生会话与IO生命周期，不在选择后创建新会话或重新执行全局寻色。已审计候选在同次搜索预算内有限补充并去重；全部区域达标优先，其他方案按区域优先级与色差排序。预测、已测和当前方案分别标记。

- [x] 原生规划器保留小候选池；初始已达标也可生成其他方案。保留旧无选择回调行为。
- [x] 控制器自动定位预算允许的目标，读回两帧后开放选择。每次选择从实际姿态重编译、审计完整路线及返回余量；不重新全局搜索，不因模型偏差直接停止。
- [x] 手选可接受较差方案，但最终accepted必须据当前实际色码计算。失败时尝试恢复选择前已测方案；刻意选较差方案不能误报为恢复失败。
- [x] 服务连接同批次选择队列，转发精简原生候选事件并保存完整日志。
- [x] 浮窗选择阶段可点击且不抢游戏焦点，执行阶段透传。结束后主界面按钮恢复，并可重开只读候选列表；下一次开始清理旧批次。
- [x] UI、教程、三个README和结果提示同步三语；双区域数组不访问不存在的第三区域，保存的三卡偏好保持。
- [x] 验证批次过期、取消、低余量零输入、手选更差、途中碰到原目标、失败返回、重复选择、初始已达标、双/三区域与精准/相似混合。
- [x] 针对新增路径运行聚焦回归，再运行精简发布检查：81项增量全通过；冻结发布集合604项、603通过、1跳过、无失败。
- [x] 制作本地候选包核对源指纹、个人数据排除和三语显示。远端扫描耗时与真实双区域准确度保留实机未验证说明。打包启动发现的候选按钮显隐问题已补回归修复。
