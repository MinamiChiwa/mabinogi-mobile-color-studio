# 截图寻色：两区精准、一相似实施计划

**目标：** 复用精准寻色中已验证的联合求解、统一优先级、实测纠偏与最佳恢复经验，使截图流程首先支持两个实际 HEX 精准纯色和一个用户容差内的相似色。不读取游戏内存，不自动套用，不新增道具消耗。

**设计：** 两个精准区域作为相似变换的锚点，第三区域只评价该变换下的实际采样位置，不以三点最小二乘挪动精准锚点。候选保留直接使用当前优先级与原目标颜色。纯色候选先探索色块内部及不同周期位置，仍保留原始像素与后续全采样扩展。截图定位先用现有特征求粗变换，再用同材质、排除 UI 的纹理做亚像素修正。细化由实际姿态与当前目标误差决定，每次移动后复测并保存最佳。

验收：两精准区域六位 HEX 完全一致，相似区域 Delta-E 不超过其设置容差；至少再次读取真实游戏色码确认。截图预测、合成测试及留存记录回放分别记录，不能宣称为新实机成功。默认参考用纯白/纯黑组合及相似灰色，算法支持用户原目标、替代色和优先级。

涉及模块：`screenshot_geometry.py`、`screenshot_search.py`、`screenshot_samples.py`、`screenshot_registration.py`、`screenshot_control.py`、`screenshot_live.py`。测试沿用对应 `test_screenshot_*.py`，增加少量独立混合目标与定位测试；不重复全量研究矩阵。计划按上述步骤顺序执行，保留原有 30 秒开局计时宽容、三秒尾余量、F9/焦点/窗口变化停止及游戏实际 HEX 验收。

执行结果与限制见 [研究记录](../../research/screenshot-mixed-precision.md)。候选0.4.4rc1已构建且151个冻结生产模块与当前源码一致；完整留存色板只读预检读全三色及113秒倒计时。尚未进行新实机路线验收，不能宣称达成初步目标；已完成本轮离线实现与交付。
