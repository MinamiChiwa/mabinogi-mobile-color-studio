# 自动更新本地验证与韩服适配结论

## 本轮结果

已接入主窗三语更新入口、GitHub 官方源检查、文件差异下载、完整/差异离线导入、独立 onefile 更新器、文件事务恢复和新程序健康握手。自动检查不下载、不安装；由用户分别决定下载与安装。更新与染色、吸管、窗口选择互斥，不改变寻色模型、首次 30 秒 OCR 宽限、最多 3 秒尾余量或 F9。

Ed25519 使用 `cryptography==46.0.5`，未保留自写算法。文件所有权、Windows 路径别名、重复/前缀冲突、重解析路径、SHA-256 和离线成员均校验。小资源合并为最多 128 项的文件组；示例冻包从约 1,200 个逐文件资产减少到 98 个 blob。GitHub 没有更新清单资产的公开 0.4.1 不会被误认为可安装版本。

“重新寻色退出”记录来自桌面会话 `20261011-222611-89b4deb9`：可重试事件已经发出，没有进入 reset，结果为 `interrupted`，错误为游戏失去焦点。按钮现在先激活已绑定 HWND/PID，再提交独立重试请求；激活失败保持按钮可用，不把浮窗锁死。不把重试当作 F9，不开启新局或确认染色。

韩服记录 `data (4).zip` 的窗口已绑定，失败在台服专用 GameAssembly/metadata 校验，0 次输入。新版失败会保存三个构建指纹并通过注册表选择已验证适配器。详细后续方案见 `superpowers/plans/2026-10-11-server-adaptation.md`。日志本身没有足够布局证据，韩服尚未完成适配与实机验收。

## 实施修正与首版边界

完整/小离线包使用同一目标所有者清单。小包的基线约束由独立签名 `offline-base.json/.sig` 携带，避免一次差异更新改变下一次基线摘要。安装备份/暂存位于安装同盘；独立 helper 位于安装树外。权限不足保持旧包，说明复制到可写本地目录；首版不自动提权。

用户修改的待替换应用文件不静默覆盖，提示保留 data 后使用完整官方包。修改过的废弃文件及未知文件保留。网络故障不阻止寻色，离线入口可在断网使用；仅 GitHub 不能保证各地区直连。

实际最终候选 `release-v0.4.2rc9-complete` 的 139 个生产模块/资源/内嵌 helper 哈希核对通过，主窗正常启动退出，独立 helper --help 正常退出；无正式或测试公钥、无 data。恢复引导只使用标准库与 EXE 内嵌 helper SHA，另保存新旧 helper 供存活 EXE 选择，模拟缺失密码库的新进程回归通过。

当前交付候选没有正式公钥/正式签名所有者清单，不可当作正式更新源。正式引导版本需维护者配置公钥、安全保管私钥、签署完整清单，并完成真实 GitHub 下载及发布验收。测试公钥仅在隔离演练包嵌入，正式候选不信任它。

用户资料、正式私钥、韩服个人日志、游戏文件和历史 fixture 不复制到 Git。本轮不覆盖桌面工具、不读取或操作游戏、不消耗染色道具。普通/管理员权限、ARM64 模拟、其他显示器与地区网络仍需正式包环境验收；韩服按后续计划先做普通界面只读诊断。

最终只读代码审查未发现剩余 Critical/Important；审查期间修正窗口选择忙碌门控、helper 失联隐藏程序、提交日志失败子进程清理、改名同内容离线 blob 和混合安装时恢复依赖。生产签名、两份历史素材和韩服实机验证仍按上文边界处理。
