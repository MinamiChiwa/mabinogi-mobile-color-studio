# ColorStudio 0.4.9

## 简体中文

- 改善精准寻色的准备流程，减少残留色板实例或短暂读取失败导致的启动阻断。
- 修复停止后色卡结果被清空的问题；无法确认当前颜色时，明确显示上次实测结果。
- 加强停止来源记录和快捷键消息校验，便于排查未按停止键却结束寻色的反馈。

**更新方式**

- 已安装用户：检查更新，下载后选择安装并重启；也可导入对应版本的 UPDATE-ONLY 离线更新包。设置、方案和记录保留。
- 首次安装：下载 `ColorStudio-v0.4.9-Windows-x64.zip` 并完整解压。**UPDATE-ONLY 仅供已有安装更新，不能用于首次安装或直接运行。** [更新指南](automatic-updates.md)

## 繁體中文

- 改善精準尋色的準備流程，減少殘留色板實例或短暫讀取失敗造成的啟動阻擋。
- 修正停止後色卡結果被清空的問題；無法確認目前顏色時，明確顯示上次實測結果。
- 加強停止來源記錄與快捷鍵訊息檢查，便於排查未按停止鍵卻結束尋色的回報。

**更新方式**

- 已安裝使用者：檢查更新，下載後選擇安裝並重新啟動；也可匯入對應版本的 UPDATE-ONLY 離線更新套件。設定、方案與記錄會保留。
- 首次安裝：下載 `ColorStudio-v0.4.9-Windows-x64.zip` 並完整解壓縮。**UPDATE-ONLY 僅供既有安裝更新，不能用於首次安裝或直接執行。** [更新指南](automatic-updates.zh-TW.md)

## English

- Improved Precise Search preparation to reduce startup failures caused by stale palette instances or temporary read errors.
- Fixed color cards being cleared after stopping. When the current color cannot be confirmed, the cards clearly show the last measured result.
- Improved stop-source logging and hotkey message validation to help investigate searches ending without a reported stop-key press.

**How to update**

- Existing users: check for updates, download, then install and restart. You can also import a matching UPDATE-ONLY offline package. Settings, presets and records are kept.
- First install: download and fully extract `ColorStudio-v0.4.9-Windows-x64.zip`. **UPDATE-ONLY packages require an existing installation; they are not for first installs and cannot be run directly.** [Update guide](automatic-updates.en.md)

## 日本語

- 精密検索の準備処理を改善し、古いパレット情報や一時的な読み取りエラーで検索を開始できないケースを減らしました。
- 停止後にカラーカードの結果が消える問題を修正しました。現在の色を確認できない場合は、直前に読み取った結果であることを明示します。
- 停止理由の記録とショートカットキーのメッセージ検証を改善し、停止キーを押していないのに検索が終了したという報告を調査しやすくしました。

**更新方法**

- インストール済みの場合：更新を確認してダウンロードし、インストールして再起動してください。対応する UPDATE-ONLY オフラインパッケージの読み込みも利用できます。設定・プリセット・履歴は保持されます。
- 初回インストール：`ColorStudio-v0.4.9-Windows-x64.zip` をダウンロードし、すべて展開してください。**UPDATE-ONLY は既存のインストールを更新するためのパッケージです。初回インストールや直接の実行には使えません。** [更新ガイド](automatic-updates.ja.md)
