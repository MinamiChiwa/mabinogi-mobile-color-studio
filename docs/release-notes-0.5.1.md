# ColorStudio 0.5.1

当前为本地候选包，包含已合并的 PR #18。

- 修复精准寻色在兼容客户端上误报“版本不适配”的两类地址发现问题：DLL 无关数据中的重复标记，以及被误当作指针的窄字段读取或写入指令。
- 台服与韩服共用更新后的发现器，按目标类实际引用的有效地址判断兼容性。
- 突出主界面顶部的“支持作者”入口，在赞助面板和五种语言 README 顶部加入咖啡赞助文案。
- 窄窗顶部按钮自动换行，保持各语言的赞助、更新等入口完整可见。

完整解压根目录“发布包”中的 `ColorStudio-v0.5.1-Windows-x64.zip` 后运行 `ColorStudio.exe`。本机现有设置和会话由构建交付流程保留在 `发布包/ColorStudio/data/`。
