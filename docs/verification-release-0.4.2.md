# v0.4.2 发布验证

用户授权给重新寻色增加「仅供测试」标注、更新 Git 并发布。发布说明以 GitHub 最新正式包 v0.4.1 为基线，使用简中、繁中及英语，概括寻色/细化优化、重试与恢复、DPI/吸管、自动更新及韩服验证入口，不沿用本地候选版的逐次开发记录。

## 回归与界面

发布集合 678 项：675 通过、3 跳过、0 失败/错误，总计 195.387 秒。缺失素材为两个原 rc16 相似模式回放和一个补充历史 OCR 档案；`release_complete=false` 保留，不扩大例外名单，也不宣称完整历史回放通过。韩服实机染色与输入响应仍待验收。

31 项更新资产、清单与语言专项通过。三语重新寻色按钮在 100%、150%、200% 缩放下实际检查，均完整显示且命中区域可访问。独立发布差异审查无阻断项。本轮不读取/操作游戏、不消耗道具。

## 正式更新引导

生产公钥保存在 `release/update-public-keys.json`，通过 `COLOR_STUDIO_UPDATE_PUBLIC_KEYS` 嵌入主程序和独立更新器。签名私钥不进入源码、输出包或 Git，使用当前 Windows 用户 DPAPI 加密并限制目录访问。本机维护材料位于 `%LOCALAPPDATA%/ColorStudioRelease/signing`；未来发布复用同一公钥并递增发布序号。

发布包包含签名所有者清单，更新资产包括清单、签名、文件 blobs 和完整离线包。v0.4.1 无更新器，需手动升级一次；没有对应的旧签名基线，不生成误导性的 v0.4.1 小离线更新包。GitHub 不通时可通过其他电脑下载离线包。

新增的韩服两个启动脚本及说明文档已纳入精确应用白名单；其他任意脚本、个人文档与 data 仍拒绝进入更新所有权。签名清单和包文件逐项比对，公开前从 draft 重新下载清单/签名和代表 blob 验证；完整资产上传后再公开。

本地证据目录：`outputs/release-0.4.2-evidence/`。用户日志、色板图、私钥及构建产物不提交 Git。
