五语 UI 的精准选项显示内存读取与较高风险警示。截图寻色使用图像和普通鼠标操作，不读取游戏内存，风险相对较低；说明也明确两方式都不保证账号安全。五语切换、窄宽布局、当前配置与保存方案回归通过。旧“精准故障时使用”提示退出当前界面和教程。

## rc2色差根因

会话 `20261013-110244-3cd5fe44` 设置三区精准黑色。原结果颜色为 `#77CFD0 / #B2C09A / #AD973D`，色差约82.58/78.52/79.68；不是单纯“三黑只能妥协”的证据。该局没有发现在窗口466像素色板上约233.27像素的实际重复周期，转入当前截图备用搜索。

定位本身基本准确，原候选逆映射取色点与实际截图变换误差为0.054/0.039/0.080像素。候选却使用几何拟合前附近深色样本 `#130000 / #02091A / #110001` 来评分，三点拟合残差约3.53/7.91/5.28像素，落在旁边浅色像素。这是候选终点评估错误，不能通过增加操作精度修复。真实终点截图颜色约 `#77D0D0 / #E0CECA / #EFAD32`，没有接近目标。

两个修复：周期验证保留强SIFT重复证据，并评价仅用于定位的平滑纹理，使紧凑窗口的分数像素重采样不再误判；采样原始RGB不变。全局与局部候选用逆映射后的终点完整RGB评估，不以附近目标点代替。可见备用分支只用实际可见、未遮罩的位置；周期分支保留全部观察颜色的相位场。未知位置不冒充可靠颜色。

原局保存图复算：实际重复周期233.2703已识别，仅用这一张图建立周期后首选终点样本为 `#000A16 / #323A35 / #1A000E`；当前截图备用分支也按实际终点评分，不再宣称三深色样本是落点颜色。这是离线预测，尚未新实机移动验收，不保证三区精准纯黑。旧25张原图的双白＋相似灰继续找到联合预测候选；双黑旧近点预测经过全色场复核后部分不达标，不能沿用原先的乐观结论。
