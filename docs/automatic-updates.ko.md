# 업데이트 안내

[简体中文](automatic-updates.md) · [繁體中文](automatic-updates.zh-TW.md) · [English](automatic-updates.en.md) · [日本語](automatic-updates.ja.md) · [한국어](automatic-updates.ko.md)

## 파일 선택

첫 설치나 수동 업그레이드에는 [GitHub Releases](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/releases)에서 전체 패키지 `ColorStudio-v<버전>-Windows-x64.zip`을 받아 전체 압축을 푼 뒤 실행하세요. 이미 설치한 도구는 아래 온라인 업데이트를 사용하며, 릴리스 페이지의 `blob-` 파일이나 매니페스트를 따로 받을 필요는 없습니다.

## 온라인 업데이트

> 도구는 먼저 미러 `v6.gh-proxy.org`를 통해 공식 릴리스 파일을 받고, 미러를 사용할 수 없으면 자동으로 GitHub에 직접 연결합니다. 미러는 전송만 담당합니다. 매니페스트는 내장 공개 키로 서명을 검증하고 모든 파일을 SHA-256으로 확인하므로 변조된 내용은 거부됩니다.

1. 메인 화면에서 **업데이트 확인**을 누르세요. 확인만으로는 다운로드나 설치를 하지 않습니다.
2. 새 버전이 있으면 **업데이트 다운로드**를 선택하세요. 변경되거나 부족한 파일만 받습니다.
3. 완료 후 **설치 후 다시 시작**을 누르세요. 검색, 스포이트, 창 선택은 먼저 끝내야 합니다.
4. 도구가 다시 열리고 설정·프리셋·기록·스크린샷은 유지됩니다.

업데이트 창에서 시작 시 자동 확인을 끄거나 후보 버전을 포함할 수 있습니다. 다운로드는 취소 후 다시 이어받을 수 있습니다.

## 수동 업그레이드와 데이터 유지

온라인 업데이트를 할 수 없으면 기존 도구를 종료하고 전체 설치 패키지를 새 쓰기 가능한 로컬 폴더에 푸세요. 기존 도구가 **실제로 사용하는 데이터 폴더**를 새 폴더의 `data`로 복사하세요. 보통 프로그램 옆에 있지만 쓰기가 불가능하면 `%LOCALAPPDATA%\MabinogiMobileColorStudio\data` 또는 임시 폴더를 사용합니다.

새 도구가 실행되고 설정을 확인할 때까지 기존 폴더를 보관하세요. EXE만 복사하지 말고 `_internal`과 별도 업데이트 프로그램도 유지하세요.

## 업데이트 문제 해결

- **접속 불가**: 미러와 GitHub 모두 연결할 수 없으면 나중에 다시 시도하거나 위의 방법으로 수동 업그레이드하세요.
- **파일 사용 중 또는 권한 부족**: 같은 폴더에서 실행 중인 다른 도구를 닫거나 전체 패키지를 쓰기 가능한 로컬 폴더에 푸세요.
- **검증 실패**: 공식 패키지를 다시 받고 로그를 보관하세요. 서명이나 프로그램 파일을 직접 수정하지 마세요.
- **구버전 설치 시간 초과**: 기존 업데이트 프로그램이 종료된 도구를 실행 중으로 판단할 수 있습니다. 다운로드가 끝났고 파일 교체 전이라면 [0.4.4 릴리스](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/releases/tag/v0.4.4)의 `ColorStudio-Update-Recovery-v0.4.4.zip`을 사용할 수 있습니다. 도구를 닫고 `Recover-Update.cmd`를 실행해 원래 설치 폴더를 선택하세요. 적용 가능한 업데이트 기록이 없으면 전체 패키지로 수동 업그레이드하고 데이터를 유지하세요.

실패 후에는 현재 버전과 업데이트 기록을 먼저 확인하세요. 도움이 필요하면 [GitHub Issues](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/issues)에 로그를 첨부하세요.
