## ファイルを選ぶ

| 用途 | ファイル | 使い方 |
|---|---|---|
| 初回インストール・手動更新 | `ColorStudio-v0.4.5-Windows-x64.zip` | すべて展開して実行 |
| 完全オフライン更新 | `UPDATE-ONLY-ColorStudio-0.4.5-win-x64.zip` | インストール済みのツールから読み込む |
| 公式 0.4.4 からの更新 | `UPDATE-ONLY-ColorStudio-from-0.4.4-to-0.4.5-win-x64.zip` | ファイルが一致する公式 0.4.4 の最終修正版のみ |

**UPDATE-ONLY は初回インストール用ではなく、展開して直接実行することもできません。** 差分パッケージが合わない場合は完全オフライン更新を使ってください。リリースページの `blob-` ファイルを個別にダウンロードする必要はありません。

## オンライン更新

1. メイン画面の**更新を確認**を押します。確認だけではダウンロードやインストールは行いません。
2. 新しいバージョンが見つかったら**更新をダウンロード**を選びます。必要な変更・不足ファイルだけを取得します。
3. 完了後に**インストールして再起動**を押します。検索、スポイト、ウィンドウ選択は先に終了してください。
4. ツールが再起動し、設定・プリセット・履歴・スクリーンショットは保持されます。

更新画面で起動時の自動確認を無効にしたり、候補版を確認対象にしたりできます。ダウンロードはキャンセル後も再開できます。

## オフライン更新

GitHub に接続できない場合は、別のパソコンで完全オフライン更新をダウンロードしてコピーします。ツール内の**オフライン更新を読み込む**で ZIP を選び、検証後に**インストールして再起動**を押してください。

更新機能がない旧バージョンは、次の手動更新を使います。

## 手動更新とデータの引き継ぎ

旧ツールを終了し、完全インストールパッケージを新しい書き込み可能なローカルフォルダーに展開します。旧ツールが**実際に使用しているデータフォルダー**を、新しいフォルダーの `data` にコピーしてください。通常はツールの隣にありますが、書き込めない場合は `%LOCALAPPDATA%\MabinogiMobileColorStudio\data` や一時フォルダーを使用します。

新しいツールが起動し、設定を確認できるまで旧フォルダーを残してください。EXE だけでなく、`_internal` と独立した更新プログラムも必要です。

## 更新できない場合

- **接続できない**：後で再試行するか、完全オフライン更新を使ってください。
- **差分パッケージが合わない**：完全オフライン更新に切り替えてください。
- **ファイル使用中・権限不足**：同じフォルダーの別のツールを終了するか、書き込み可能なローカルフォルダーに完全パッケージを展開してください。
- **検証に失敗した**：公式パッケージを取得し直してログを残してください。署名やプログラムファイルを手動で変更しないでください。
- **0.4.3・初期 0.4.4 でインストールがタイムアウトする**：旧更新プログラムが、終了済みのツールを起動中と判定する場合があります。ダウンロード済みでファイル置換前なら、[0.4.4 リリース](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/releases/tag/v0.4.4) の `ColorStudio-Update-Recovery-v0.4.4.zip` を使えます。ツールを終了し、`Recover-Update.cmd` を実行して元のインストール先を選んでください。利用できる更新記録がない場合は完全パッケージで手動更新し、データを引き継ぎます。

失敗後は現在のバージョンと更新記録を確認してください。問い合わせはログを添えて [GitHub Issues](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/issues) へ。
