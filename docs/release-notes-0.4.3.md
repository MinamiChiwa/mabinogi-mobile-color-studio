# Color Studio 0.4.3

## 简体中文

**首次使用请下载 `ColorStudio-v0.4.3-Windows-x64.zip`，完整解压后运行。** `UPDATE-ONLY-` 开头的文件仅用于工具内导入离线更新，不能直接运行；从 0.4.2 升级可使用差异更新包。配置与方案保留。

相较 0.4.2：
- 支持台服、韩服、日服；韩服和日服仍在测试中。服务器选择与游戏窗口检测联动。
- 改善多区域优先级、纯黑/纯白不可精准命中时的妥协搜索，以及旋转、重试和最佳结果恢复。细化过程显示当前结果与进度。
- 游戏字体辅助识别色码与倒计时，实际色卡持续刷新；新截图寻色替换旧图像策略，供精准寻色故障时使用。
- 新增自然日语、韩语界面及说明，现支持五种界面语言；清理旧预检脚本和过时说明。

默认仍为精准寻色。F7 重新寻色仅供测试，F9 停止；是否套用由玩家在游戏内手动决定。多色精准成功率不作保证。

## 繁體中文

**首次使用請下載 `ColorStudio-v0.4.3-Windows-x64.zip` 並完整解壓。** `UPDATE-ONLY-` 開頭的檔案僅供工具內匯入離線更新，無法直接執行；0.4.2 可使用差異更新包，設定與方案會保留。

相較 0.4.2：支援台服、韓服與日服（韓服、日服仍在測試）；改善多區域優先順序、折衷搜尋、旋轉、重試及最佳結果回復；遊戲字型輔助辨識色碼與倒數，實測色卡持續更新；新的截圖尋色取代舊圖像策略。新增日語、韓語介面與說明，移除舊預檢腳本。

預設精準尋色；F7 重新尋色僅供測試，F9 停止，套用仍須在遊戲內手動確認。多色精準無法保證成功。

## English

**First installation: download `ColorStudio-v0.4.3-Windows-x64.zip` and extract the entire archive.** Files starting with `UPDATE-ONLY-` are for Import offline update inside the app, not installation. The smaller delta package requires official 0.4.2. Settings and presets are retained.

Since 0.4.2: Taiwan, Korea and Japan server selection is linked to window detection; Korean and Japanese support is still in testing. Improved region priorities, compromise search, rotation, retries and best-result recovery. Refinement shows current results and progress. Game-font-assisted HEX/countdown recognition and continuously refreshed measured colors improve feedback. Screenshot Search replaces the old visual strategy as a fallback. Japanese and Korean bring the interface to five languages; obsolete preflight scripts were removed.

Precise Search remains the default. F7 retry is for testing; F9 stops. Apply results manually in the game. Multiple exact matches are not guaranteed.

## 日本語

**初めて使う場合は `ColorStudio-v0.4.3-Windows-x64.zip` をダウンロードし、すべて展開してください。** `UPDATE-ONLY-` で始まるファイルは、アプリのオフライン更新の読み込み専用です。単体では起動できません。差分更新パッケージは公式 0.4.2 用です。設定とプリセットは引き継がれます。

0.4.2 からの変更：台湾・韓国・日本のサーバー選択をゲームウィンドウの検出に連動しました。韓国版・日本版の対応はテスト中です。部位の優先順位、近似色の探索、回転、再検索、最良の実測結果への復帰を改善しました。微調整中も現在の結果と進行状況を表示します。ゲーム内フォントを使った色コード・残り時間の読み取りを改善し、実測色を継続更新します。旧画像検索をスクリーンショット検索に置き換え、日本語・韓国語の画面と説明書を追加しました。旧事前チェックスクリプトは同梱しません。

標準は精密検索です。F7 の再検索はテスト用、F9 で停止します。結果の適用はゲーム内で手動で行ってください。複数部位の完全一致は保証できません。

## 한국어

**처음 사용하는 경우 `ColorStudio-v0.4.3-Windows-x64.zip`을 다운로드한 뒤 전체 압축을 풀어 주세요.** `UPDATE-ONLY-`로 시작하는 파일은 앱 내 오프라인 업데이트 가져오기 전용이며 직접 실행할 수 없습니다. 차등 업데이트 패키지는 공식 0.4.2 버전에서만 사용할 수 있습니다. 설정과 프리셋은 유지됩니다.

0.4.2 대비 변경: 대만·한국·일본 서버 선택과 게임 창 감지를 연동했습니다. 한국 및 일본 서버 지원은 테스트 중입니다. 영역 우선순위, 근사 색상 검색, 회전, 다시 검색 및 최적 실측 결과 복원을 개선했습니다. 세부 탐색 중 현재 결과와 진행 상태를 표시합니다. 게임 내 글꼴로 색상 코드와 남은 시간 인식을 보완하고 실측 색상을 계속 갱신합니다. 기존 이미지 검색을 스크린샷 색상 검색으로 교체하고 일본어·한국어 UI와 설명서를 추가했습니다. 이전 사전 점검 스크립트는 제거했습니다.

기본 모드는 정밀 색상 검색입니다. F7 다시 검색은 테스트용이며 F9로 중지합니다. 결과 적용은 게임 내에서 직접 결정하세요. 여러 영역의 정확한 색상 일치는 보장되지 않습니다.
