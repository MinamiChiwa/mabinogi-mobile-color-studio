# 已验证妥协结果后的受保护细化

用户要求：可继续提高精准度，但必须在时间内完成；不能试到更差的位置后因超时留下差结果。严守原来的精准 HEX 规则，不因模型姿态残差停止已授权路线。

1. 保存 rc11 最后一局的实际终点、色板和时间证据，离线寻找短细化动作；试探前完整模拟并审计返回路线，不能把正反滚轮当作互逆。
2. 先用带真实量级读取/截图耗时的测试复现旧控制器不继续细化；测试搜索超时、额度不足、实际变差、恢复及模型残差。
3. 细化仅从截图及原生回读一致的结果开始。把搜索、试探、实际回读、返回、纠正及最终截图的完整预算预留在当前截止之前，额度不足保持原位。
4. 实际结果改善才替换保底点；实际结果变差立即按实际姿态修正返回。恢复成功须用当前 HEX 与原保底色差比较，不能用预测或历史截图冒充。
5. 运行相关回归、全套检查与独立审查。制作 rc12 候选包并核对打包模块和源码一致，报告离线验证范围；本阶段不消耗道具、不操作游戏。

边界：F9、进程/会话变化、失去有效输入和回读不由色差保护覆盖。无法证明可回到不劣于保底结果的短动作不执行。
