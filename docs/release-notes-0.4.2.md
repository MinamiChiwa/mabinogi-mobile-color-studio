# 0.4.2 — 寻色优化与自动更新

## 简体中文

相对 v0.4.1：

- 优化寻色、旋转及细化路线，保留较好的实测结果；细化计算期间显示当前配色和色差。
- 精准模式取消其他预测候选，新增「重新寻色（仅供测试）」/ F7；加快连续缩放，修复重试时间判断与上一妥协方案恢复。
- 修复高 DPI、多屏吸管位置偏移，以及部分启动、退出和界面操作问题；精简回归测试与项目文档。
- 新增用户决定的 GitHub 文件更新和离线更新，保留配置、方案与记录。v0.4.1 及更早版本需先手动升级一次；以后仅下载变化文件。
- 增加韩服预检与验证入口，目前仍待实机染色验收。

首次安装/手动升级请下载 `ColorStudio-v0.4.2-Windows-x64.zip`。`ColorStudio-offline-0.4.2-win-x64.zip` 供工具内「导入离线更新」使用；GitHub 无法直连时，可在其他电脑下载后复制过来。

重新寻色仅供测试。程序不会自动开启染色或套用结果。

## 繁體中文

相較 v0.4.1：

- 優化尋色、旋轉與細化路線，保留較好的實測結果；細化計算期間顯示目前配色與色差。
- 精準模式取消其他預測候選，新增「重新尋色（僅供測試）」/ F7；加快連續縮放，修正重試時間判斷與先前妥協方案恢復。
- 修復高 DPI、多螢幕吸管位置偏移，以及部分啟動、退出與介面操作問題；精簡回歸測試與專案文件。
- 新增由使用者決定的 GitHub 檔案更新與離線更新，保留設定、方案與紀錄。v0.4.1 及更早版本需先手動升級一次；之後僅下載變更檔案。
- 新增韓服預檢與驗證入口，目前仍待實際染色驗收。

首次安裝/手動升級請下載 `ColorStudio-v0.4.2-Windows-x64.zip`。`ColorStudio-offline-0.4.2-win-x64.zip` 用於工具內「匯入離線更新」；無法直接連線 GitHub 時，可在其他電腦下載後複製過來。

重新尋色僅供測試。程式不會自動開啟染色或套用結果。

## English

Changes since v0.4.1:

- Improves search, rotation and refinement routes while retaining better measured results. Current colors and differences remain visible during refinement calculations.
- Replaces predicted alternatives in Precise Search with “Retry search (Testing only)” / F7. Speeds up continuous zoom and fixes retry timing and restoration of the previous compromise.
- Fixes high-DPI and multi-monitor eyedropper offsets, plus startup, shutdown and UI control issues. Streamlines regression tests and project documentation.
- Adds user-controlled GitHub file updates and offline updates while preserving settings, presets and records. v0.4.1 and earlier need one manual upgrade; subsequent updates download only changed files.
- Adds Korean preflight and validation launchers. Live dye validation is still pending.

For installation or manual upgrades, download `ColorStudio-v0.4.2-Windows-x64.zip`. Use `ColorStudio-offline-0.4.2-win-x64.zip` with Import offline update. If GitHub is unreachable, download it on another computer and copy it over.

Retry search is for testing only. The tool never starts dyeing or applies a result automatically.
