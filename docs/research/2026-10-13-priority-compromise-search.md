# 按区域优先级寻找近似妥协方案

## 改动

本轮落实已确认的策略：全部启用区域达标始终最优；否则按用户优先级依次比较该区域是否达标与色差。未达标色差采用固定 0.5 ΔE 档位，避免很小的变化压过后续区域；档位不改变 HEX 精准验收或相似模式容差。相似区域进入设定容差后让后续区域优先改善。档位全部相同时，统一以实际最大、平均 Delta-E 决定顺序。

该顺序应用于色板数学候选、真实鼠标路线终点、截图策略候选、实际最佳结果与恢复。截图预测仍保留几何残差代价，不因原样本颜色接近就把偏离取色点的位置当作命中。未带优先级的旧记录保持原有评分。

某一区域没有精准目标时，仍扫描完整周期采样位置并保存其近似位置。首批包含低色差位置及不同空间分区的代表；时间允许时依次扩展到 128、512 和全部采样位置，保留已有候选及原精准位置。近似位置参与平移、缩放、旋转的联合计算，但所有终点仍按原始用户目标重新评分。分别最接近的颜色不是同时可达证明。

局部细化改为约两秒 CPU 批次，并继续同一未移动参考下的候选迭代器。找到完整审计的有效改善即可返回；尚有候选时继续计算而非重新开始，不增加截图、内存读或游戏输入。初始生成准备或单个完整审计可能跨过批次长度，批次不是强制两秒中断。停止与真实截止仍在内部检查；参考、目标或排除路线改变、已达标或异常时清理续算状态。

现有实际最佳结果、完整路线重放、依据实测状态纠偏及一次必要恢复保留。30 秒开局 OCR 宽容和最多三秒末尾余量不变，没有新增会话提前停止条件。

## 验证与审查

新增失败回归先确认了高优先级被低优先级精准命中压过、缺精准色时无近似联合方案、相似高优先级不让出容差内细化、跨路径色差档位平局不一致，以及细化 CPU 无续算功能。实现后分别通过。

旧路线 fixture 的排序是派生策略字段，回放时按原姿态和规则重新计算；原颜色、真实旋转残差、完整路线与其他审计字段不变。预算回归改用明确两动作候选，避免搜索找到合法零动作妥协导致测试不再测预算。开局宽容回归明确检查其 21 秒初始帧；不要求真实 CPU 规划后的晚期帧永远属于开局。

一次快速回归选择 741 项：727 通过、14 整项历史素材跳过、零失败/错误，耗时 173.389 秒；19 次 skip 事件包含子测试。最终近似候选扩展在该回归后增加，随后运行其相关周期搜索、优先级、路线预算及细化专项：56 项中 54 通过、2 项历史素材跳过，耗时 19.622 秒。64 项颜色更新、三语及恢复边界专项中 60 通过、4 项历史素材跳过。统一截图/原生评分与最佳结果专项 82 项中 78 通过、4 项历史素材跳过；这些计数重合，不相加作为独立覆盖量。有限历史素材缺失仍明示，不将本轮视为全量正式发布验收。

尾部预算测试曾使用固定不前进的模拟时钟，扩展搜索后不会触发该模拟 deadline，导致测试重复巨大候选枚举。将此协议测试隔离为固定已完成的真实两动作路线响应，继续由生产规划器完整重放和验收；没有改变生产搜索预算。它不再重复全球搜索矩阵，该矩阵由独立测试及上述本局完整生产规划复算覆盖。

独立审查发现已达标的新参考帧可能保留旧 pending 状态；已先复现失败再清理状态，三个续算回归及一个 controller 批次回归独立复验通过。本轮只交付本地 rc12 候选，尚无新增实机染色验证或公开发布。
