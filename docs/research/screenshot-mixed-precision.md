# 截图寻色：两区精准、一相似验证

本轮目标是复用精准寻色的联合求解、优先级、实测纠偏和最佳恢复经验。截图后端仅使用屏幕图像、已有解包字体和普通输入；本轮没有操作游戏或消耗染色剂。

## 第三区域的约束

达标必须同时满足两区完整六位 HEX 精准一致、第三实际色差不超过用户容差。不会自动提高第三容差或改变区域优先级。固定两精准点只是一种求解方法：第三仍参与候选保留和整体排序，所有区域都达标的方案优先于任何妥协。

如果没有兼顾三区的候选，妥协结果继续按玩家设置的优先级排序。低优先级区域仍可能偏差较大，这是明确显示的未达标结果，不能称为成功。有限截图覆盖或有限计算时间内没找到，也不能证明无解。

## 修改与发现

- 两精准锚点避免三点最小二乘把已对准的点挪动。未采到完整精准色时保留原妥协分支；第三没有容差内样本时仍保留两精准锚点，检查第三完整原始颜色池。
- 原目标质量和优先级参与几何候选的早期保留，防止可行颜色组合先被几何成本筛掉。纯色首批候选分散覆盖色块，优先内部位置。相似第三色的位置树保留完整候选；精准锚点池逐级扩展，仍受本局实际时间约束。
- 图像定位用 SIFT 确定粗变换后，以目标图整像素对逆映射源图做一次插值修正；训练和独立保留像素分别评价。修正定位不混合采样 RGB。原先再次插值目标图会把正确变换改坏，已用正确种子与独立 SIFT 反例复现并修复。
- 局部微调从当前实测姿态规划，不累加请求位移。试探较差时恢复实测最佳；恢复未完成时停止新的局部及全局试探，继续最终恢复。不会把历史最佳颜色当作当前颜色。
- 只有新帧读取连续达标才报告成功。恢复的一次达标不能覆盖之前失败的确认。最终确认时关闭界面或停止，发布未验证结果并保留历史最佳信息。

已知旋转0.43度、缩放1.006和位移的独立合成图验证：带噪种子修正后取色点误差小于0.1像素。三个原先恶化的精确1/32像素位移案例，当前 SIFT 加修正误差约0.0002–0.0004像素；正确种子未被改坏。无纹理图不生成定位。

真实六对连续截图暖运行约0.28–0.35秒，不满足独立像素改善的修正被拒绝。没有独立真实坐标真值，不能据此宣称实机达到相同误差。20组规则组合、每组50个候选的向量/标量排名一致，包含不同精准区域、替代色、优先级及非优先级规则。
