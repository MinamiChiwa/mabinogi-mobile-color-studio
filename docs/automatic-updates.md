# 自动更新与离线更新

工具启动后最多每 24 小时后台检查一次 GitHub，检查不下载、不安装。主界面可手动检查，关闭自动检查，或主动选择候选版通道。发现兼容版本后显示版本与按本机文件哈希计算的下载量。

用户点击“下载更新”后，只下载缺少或变化的文件；小资源按有界文件组压缩，DLL 与主程序保持独立。下载校验 SHA-256，支持取消和断点续传。下载完成仍需点击“安装并重启”。染色、吸管与选窗口期间暂停更新下载，禁止安装，F9 和原寻色逻辑不受更新检查影响。

签名清单及离线包由 Ed25519 验证。更新只管理明确的程序文件，不删除未知用户文件，保留当前实际使用的 data 路径、设置、方案、历史与截图。被改动的旧废弃文件保留；待替换的程序文件若被修改则中止安装，提示保留 data 并使用完整官方包。当前候选不提供静默覆盖用户修改文件。

安装使用独立 ColorStudioUpdater.exe，正常等待主程序退出。暂存/备份位于安装目录所在磁盘，逐文件写前日志、备份、替换；新程序完成依赖、文件、OCR 与隐藏 Tk 健康检查，并完成 UI 就绪握手后提交。健康失败恢复旧程序文件，不回滚用户数据。保留最近更新日志与备份以便故障恢复。

网络仅使用 GitHub 官方 HTTPS，沿用系统代理与证书。仅 GitHub 不能保证所有地区直连。可在另一台能访问 GitHub 的电脑下载完整离线包，复制过来通过“导入离线更新”安装。小离线差异包只适用于明确基线；不匹配时使用完整离线包，不自动联网补齐。

0.4.1 及更早包没有更新器，需要首次手动安装一次正式引导包。0.4.2 正式引导包嵌入生产公钥并包含签名所有者清单，后续版本可在工具内更新。没有生产公钥的开发候选不作为正式更新源。

安装目录需为可写本地目录，UNC 和重解析路径暂不支持。遇到权限或另一个同目录工具实例时保持原版；请正常退出副本，或将完整官方包解压到可写本地目录。更新器不会自动提权、强杀游戏、要求关闭安全软件或切换数据账户。

## 下载哪个文件

- 首次安装：`ColorStudio-v0.4.3-Windows-x64.zip`，解压完整目录运行。
- 完整离线更新：`UPDATE-ONLY-ColorStudio-0.4.3-win-x64.zip`，在旧工具内导入。
- 0.4.2 差异离线更新：`UPDATE-ONLY-ColorStudio-from-0.4.2-to-0.4.3-win-x64.zip`，仅适用官方 0.4.2。

带 `UPDATE-ONLY-` 的文件不是安装包，不能直接解压运行。在线更新会自行选择缺少或变更的文件，不需要手动下载 blobs。

## 维护者本地命令

```powershell
$env:PYTHONPATH='work/studio'
$env:COLOR_STUDIO_UPDATE_PUBLIC_KEYS='<公开 key_id 到 32-byte hex 公钥的 JSON>'
python work/studio/build_release.py
python scripts/build_update_assets.py --package <干净包> --out <资产目录> --version <版本> --channel stable --key-file <外部私钥> --key-id <公钥ID> --release-sequence <递增序号> --previous-manifest <上一版清单>
python scripts/verify_update_assets.py <资产目录> --package <干净包> --public-keys <公钥JSON>
```

公开包不包含签名私钥或测试种子；测试 seed 仅保留测试代码，未由生产导入。正式发布前核对嵌入公钥、所有者清单以及便携包逐文件一致，再将清单/签名和全部 blobs 一次上传到 draft。资产齐全并从 GitHub 复验后才发布。不得发布测试签名演练产物。
