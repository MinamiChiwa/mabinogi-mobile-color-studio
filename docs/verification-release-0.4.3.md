# v0.4.3 发布验证

本轮由用户授权更新 Git 并发布，以正式 v0.4.2 为发布说明基线。包含此前 rc12 的优先级联合近似搜索、游戏字体识别与实际颜色更新、截图备用策略、三服选择，以及本轮五语界面和发布整理。韩服、日服仍为测试状态；没有新增游戏进程读取、实机染色或道具消耗。

## 回归范围

发布集合运行 806 项，首次为 785 通过、20 整项跳过、1 次离线 worker 等待超时。将旧项目中仍存在的八组最小回放素材恢复到当前本地路径后，对全部跳过和失败项重跑 21 项：18 通过、3 跳过，零失败/错误。最终所选合同为 803 通过、3 跳过，无未解决失败。34 项最终语言、更新运行时、优先级和测试选择专项通过。

缺失的三个历史案例为两个原 rc16 相似模式截图回放与一个补充 OCR 档案。`release_complete=false` 保留，不扩大例外、不宣称完整历史回放通过。测试报告保留初次超时和后续复验记录。

实际 Tk 验证覆盖五语动态切换、HEX 与服务器选择保留、窄宽布局、教程和更新窗口。日语与韩语由独立审查核对游戏名称、染色术语、占位符及换行；更新子系统独立文案与更新器失败提示一并补齐。

## 发布与更新约定

正式便携包：`ColorStudio-v0.4.3-Windows-x64.zip`。

完整离线包：`UPDATE-ONLY-ColorStudio-0.4.3-win-x64.zip`；官方 0.4.2 差异包：`UPDATE-ONLY-ColorStudio-from-0.4.2-to-0.4.3-win-x64.zip`。这两项仅用于工具内导入，不作为首次安装包。在线更新按文件差异下载。

旧版 0.4.2 清单解析器已核对十份新版文档路径；日、韩 README 与服务器说明放在 `_internal/docs`，避免旧更新器拒绝新增根目录文件。旧韩服预检 CMD、window-check 脚本和过时说明退出发布包。原白名单仍可校验旧签名基线，更新仅移除未被用户修改的废弃官方文件。

生产签名复用既有公钥，私钥继续保存在工作区外，使用当前 Windows 用户 DPAPI 保护。正式清单发布序号从 1 递增到 2；签名、所有权、文件 blobs、便携 ZIP、EXE 健康检查与隔离升级均须在公开前核对。
