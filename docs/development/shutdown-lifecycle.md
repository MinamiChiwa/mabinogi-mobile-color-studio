# 主窗口关闭后进程残留

2026-11-05，用户关闭本地 0.5.0 后仍有后台进程。只读进程栈显示主线程停在 `app.exec()`，预览线程池处于空闲等待，没有寻色工作线程。

原因是寻色浮窗 `Overlay.qml` 无条件拒绝关闭事件。Qt 退出时也会向已经创建、后来隐藏的浮窗发送关闭事件，导致退出被取消。主窗口已经获准关闭，因此用户看到窗口消失，但进程仍在。

主程序现在在寻色工作安全结束后，放行浮窗关闭并解除原生浮窗注册，再保存设置和退出。普通浮窗关闭继续保留停止寻色及收起行为。

真实 Qt 子进程测试覆盖主窗口关闭和退出请求，以及未打开、结果显示中、结果已收起三种浮窗状态。修复前后四种曾打开浮窗的组合由超时退出变为正常退出；完整离线测试通过。未操作游戏，不代表游戏实机效果验证。
