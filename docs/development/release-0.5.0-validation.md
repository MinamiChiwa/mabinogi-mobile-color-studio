# 0.5.0 发布验证

2026-11-05（Asia/Tokyo），`v0.5.0` 已作为 stable 正式发布。标签与实际构建提交均为 `cf1b29b`；后续文档和升级演练工具的收尾提交不改变已发布生产源码或资产。

正式包包括台韩兼容客户端地址发现、截图寻色收敛和恢复优化、最近 10 次完成会话保留，以及[关闭后残留进程修复](shutdown-lifecycle.md)。自适应逻辑随包分发，每台电脑独立验证；[兼容边界和本机证据](client-adaptation.md)仍适用。

## 已验证

- 完整离线测试通过，涵盖真实 Qt 子进程的两种退出入口和三种浮窗状态；冻结包的 166 个生产模块、QML、资源及构建身份与源码一致。
- 既有生产信任身份验签通过，stable 发布序号为 12，905 个程序文件及全部更新 blob 校验通过；冻结程序健康检查通过。
- 隔离 0.4.10 升级成功。带已有迁移标记的配置字节保持一致；无标记的旧格式仅执行既有默认策略迁移，颜色规则、方案内容、历史、会话和未知文件均保留。
- 本机交付前后 197 个个人数据文件哈希一致，完整 ZIP 不含个人数据。成功交付后清理上一测试包，保留修改或未知文件及正式完整包基线。
- GitHub 公开资产集合与本地的 301 个资产及尺寸一致，完整 ZIP 的服务端摘要匹配本地。镜像能发现 0.5.0，生产清单验签通过；经公网下载的完整 ZIP 大小与 SHA-256 也匹配本地。

完整 ZIP 为 `ColorStudio-v0.5.0-Windows-x64.zip`，354,523,314 字节，SHA-256：

## 验证限制

本机 GitHub 直连更新发现返回网络不可用；不能声称直连路径本次通过。镜像签名验证与完整下载通过，GitHub API 的公开状态、资产集合和服务端摘要已独立核对。

本轮没有自动操作游戏或消耗道具。离线测试、包健康检查和升级演练不代表台韩新客户端的完整实机寻色验收，也不代表跨设备、4K 耗时及任意未来客户端更新都已验证。

首次升级演练的旧夹具未携带迁移标记，将预期的策略迁移误判为字节变化；原失败报告保留，演练工具已拆分验证现有配置与旧格式迁移，并对迁移结果作完整内容比较，其他记录仍要求哈希一致。
