# ColorStudio 0.4.8

## 简体中文

- 改善更新检查：优先通过 GitHub 官方下载地址读取更新信息，减少“请求已达限制”对更新的影响；连接失败时再尝试备用接口，更新包仍需通过生产签名验证。
- 新增新版韩服客户端的内存模式适配，保留旧版兼容。韩服和日服仍在测试中。

**更新方式**

- 已安装用户：检查更新后下载、安装并重启，保留设置、方案和记录。旧版若提示 GitHub 请求限制，请使用离线更新完成这次升级。
- 离线更新：在工具内导入 `UPDATE-ONLY-ColorStudio-0.4.8-win-x64.zip`，也可选用匹配当前 0.4.4／0.4.5／0.4.6／0.4.7 安装的增量包；不匹配时使用完整离线更新包。
- 首次安装：下载 `ColorStudio-v0.4.8-Windows-x64.zip`。**UPDATE-ONLY 不能用于首次安装或直接运行。** [更新指南](automatic-updates.md)

## 繁體中文

- 改善更新檢查：優先從 GitHub 官方下載網址讀取更新資訊，減少「請求已達限制」對更新的影響；連線失敗時再嘗試備用介面，更新套件仍須通過正式簽章驗證。
- 新增新版韓服用戶端的記憶體模式適配，保留舊版相容性。韓服與日服仍在測試中。

**更新方式**

- 已安裝的使用者：檢查更新後下載、安裝並重新啟動，保留設定、方案與紀錄。舊版若提示 GitHub 請求限制，請使用離線更新完成這次升級。
- 離線更新：在工具內匯入 `UPDATE-ONLY-ColorStudio-0.4.8-win-x64.zip`，也可選用符合目前 0.4.4／0.4.5／0.4.6／0.4.7 安裝的差異套件；不符時使用完整離線更新套件。
- 首次安裝：下載 `ColorStudio-v0.4.8-Windows-x64.zip`。**UPDATE-ONLY 不能用於首次安裝或直接執行。** [更新指南](automatic-updates.zh-TW.md)

## English

- Improved update checks: the app now reads update information from GitHub's official download URLs first, reducing interruptions caused by API request limits. It tries the API if the download endpoint is unavailable. Updates still require a valid production signature.
- Added memory-mode adaptation for the newer Korean client while retaining the older build. Korean and Japanese support remains in testing.

**How to update**

- Existing users: check for updates, download, then install and restart. Settings, presets and records are kept. If your older version reports a GitHub request limit, use an offline package for this upgrade.
- Offline updates: import `UPDATE-ONLY-ColorStudio-0.4.8-win-x64.zip` in the app, or a delta package matching your 0.4.4, 0.4.5, 0.4.6 or 0.4.7 installation. Use the full offline update if the baseline does not match.
- First install: download `ColorStudio-v0.4.8-Windows-x64.zip`. **UPDATE-ONLY packages are not for first installs and cannot be run directly.** [Update guide](automatic-updates.en.md)
