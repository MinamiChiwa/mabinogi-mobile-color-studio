# 0.5.0 发布提案

## Why

用户已批准将本地测试的 0.5.0 发布。当前五语说明仍引用旧安装包，测试包的构建提交早于实际功能改动，需要同步文档并建立可追溯的正式交付记录。

## What Changes

- 同步五语 README、发行说明、更新指南和当前维护文档，保留历史故障报告的原始证据。
- 从包含已批准改动的提交构建同一功能版本，使用既有生产密钥签署 stable 更新清单，发布序号递增至 12。
- 校验完整包、签名及隔离升级后发布 GitHub 资产；完整 ZIP 集中在根目录“发布包”，保留必要的更新基线。
- 如实描述台韩客户端兼容发现的限制、截图收敛修复和最近 10 次会话保留策略，不承诺任意未来客户端均兼容。
- 修复发布准备期间确认的寻色浮窗阻止退出问题，并用真实 Qt 子进程验证正常结束。

## Capabilities

### New Capabilities

- `release-delivery`：同一版本的文档、完整安装包和签名在线更新保持一致，保留个人记录并可追溯至对应源码。

### Modified Capabilities

无现有规格；本次不再修改已测试的寻色算法。

## Impact

影响五语使用文档、发行说明、发布元数据、本地构建和 GitHub 发行。既有源码整理及客户端适配、截图收敛和保留策略一并进入版本历史；个人数据、私钥和构建产物不进 Git。
