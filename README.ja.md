# Color Studio · マビノギモバイル

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

**ColorStudio 0.4.7** は、マビノギモバイル台湾版に対応する Windows 用のカラー検索ツールです。韓国版・日本版はテスト中です。指定した色に合わせてパレットを操作し、結果の適用はゲーム内でユーザーが決めます。

## 1. インストール

[GitHub Releases](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/releases) から **`ColorStudio-v0.4.7-Windows-x64.zip`** をダウンロードし、すべて展開して `ColorStudio.exe` を実行してください。`_internal` フォルダーは実行ファイルの隣に置いたままにします。Python や Tesseract を別途インストールする必要はありません。

**`UPDATE-ONLY` は更新専用です。初回インストールには使えず、展開して直接実行することもできません。** すでにお使いの場合は下の「更新」をご覧ください。

## 2. 色を検索する

1. **サーバーとゲームウィンドウ**を選びます。解像度の指定は不要です。ウィンドウの位置やサイズは開始前に調整してください。
2. 対象の**染色部位**を有効にし、目標色、一致条件、優先順位を設定します。HEX 入力、カラーピッカー、スポイトが使えます。代替色も一致対象です。優先順位 1 が最優先です。
3. **F8／検索開始**を押し、案内に従ってゲームの染色画面を開きます。パレットを開いた後からツールを開始することもできます。
4. 自動操作中はゲームを最前面に保ち、マウスの操作やウィンドウの移動・サイズ変更を避けてください。結果はゲーム内で手動で適用します。

**検索方式**と、各部位の**一致条件**は別の設定です。

| 設定 | 選択肢 | 内容 |
|---|---|---|
| 検索方式 | スクリーンショット検索（標準） | スクリーンショットとマウス操作を使い、ゲームのメモリは読み取りません |
| 検索方式 | 精密検索 | ゲームのメモリを読み取り、パレットの操作を計画します |
| 一致条件 | 完全一致（HEX） | 6 桁のカラーコードが一致する色を探します |
| 一致条件 | 近似色 | 部位ごとの許容色差で探します。値が小さいほど目標に近い色が必要です |

スクリーンショット検索のリスクは比較的低く、メモリを読み取る精密検索は検知やアカウントへの制裁のリスクが高くなります。スクリーンショットと自動マウス操作もアカウントの安全を保証するものではありません。

有効な全部位で条件を満たす組み合わせを優先し、近似結果を選ぶ場合は設定した優先順位で比較します。2 部位のパレットでは存在しない3部位目を自動で除外し、保存済みの設定は変更しません。

## 3. 結果を見る

- **目標達成**：ゲームから読み取った各部位のカラーコードを確認し、適用するかゲーム内で決めてください。
- **一部の目標が未達成**：現在の色と部位ごとの色差を確認し、調整、再検索、結果の使用を選びます。
- **前回の実測（現在は未確認）**：以前に読み取った色です。ゲームの現在の画面を確認してください。

すべての目標を満たせない場合は、部位の優先順位に従い、全体の色差に加えて色相と彩度も考慮し、目標の色味をできるだけ保つ組み合わせを選びます。表示する色差、近似色の許容色差、完全一致（HEX）の達成条件は変わりません。

計算中はパレットが動かないことがあります。フローティングウィンドウに処理段階と読み取った色を表示します。

色、一致条件、優先順位は自動保存されます。**プリセット保存**で設定に名前を付けて保存し、編集・読込・削除できます。編集したプリセットを現在の検索で使うには読み込んでください。検索履歴と設定プリセットは別に保存されます。

## 4. 停止と再検索

- **F9／停止**：自動操作を終了します。ゲーム内で現在の色を確認してください。
- **F7／再検索（テスト用）**：パレットを縮小し、同じ染色の残り時間と目標設定で検索し直します。カウントダウンはリセットされず、追加の染色剤も使いません。

ツールは染色画面の開始、結果の確定・適用・取消を自動では行いません。

## 5. 更新

メイン画面の**更新を確認**から新しいバージョンを探し、**更新をダウンロード**を選びます。完了後に**インストールして再起動**を押してください。設定・プリセット・履歴は保持されます。

GitHub に接続できない場合は `UPDATE-ONLY-ColorStudio-0.4.7-win-x64.zip` を入手し、ツール内の**オフライン更新を読み込む**を使ってください。初回インストールには完全パッケージを使います。

## ヘルプと問題の報告

- **ウィンドウが見つからない**：ゲームを起動し、対応するサーバーを選んでウィンドウ一覧を更新してください。
- **アクセス権限が足りない**：ゲームとツールを同じ権限で実行してください。ゲームが管理者として動いている場合は、ツールも管理者として開き直します。
- **ウィンドウを移動・サイズ変更した**：F9 で停止し、F8 で現在のウィンドウを認識し直してください。
- **問題を報告する**：[GitHub Issues](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/issues) に今回のログを添付してください。報告のために染色剤を再び使う必要はありません。

データは通常、実行ファイルの隣の `data` に保存します。書き込めない場合は `%LOCALAPPDATA%\MabinogiMobileColorStudio\data`、必要に応じて一時フォルダーを使います。手動で移行する際は、実際に使用しているデータフォルダーをコピーしてください。
