# 염색 공방 · 마비노기 모바일

제작: **南千和 (MinamiChiwa)** · [Afdian](https://afdian.com/a/minamichiwa) · [Patreon](https://patreon.com/chiwaminami)

**ColorStudio 0.4.4**은 마비노기 모바일 대만·한국·일본 서버를 지원하는 Windows용 자동 색상 검색 도구입니다. **한국·일본 서버는 아직 테스트 중입니다.** 기본 스크린샷 검색은 원본 이미지, 위치 분석과 게임의 실제 HEX 확인을 통해 이동·확대·축소·회전을 계획하며 게임 메모리를 읽지 않습니다. 정밀 검색은 직접 선택할 수 있으며 게임 프로세스 메모리를 읽습니다. 지원 범위는 [서버 안내](docs/server-adaptation/server-selection.md)를 참고해 주세요.

게임 메모리를 읽지 않아 상대적으로 위험도가 낮은 스크린샷 검색을 권장합니다. 정밀 검색은 게임 메모리를 읽으므로 위험도가 높고, 탐지 또는 계정 제재로 이어질 수 있습니다. 스크린샷과 자동 마우스 조작도 계정 안전을 보장하지 않습니다. 위험을 고려하여 사용 여부를 결정해 주세요. 후원은 자율이며 기능에 영향을 주지 않습니다. 이 도구는 AI의 도움을 받아 개발했습니다.

## 설치 및 사용

처음 설치할 때는 전체 휴대용 패키지 `ColorStudio-v0.4.4-Windows-x64.zip`을 받아 압축을 모두 푼 뒤 `ColorStudio.exe`를 실행해 주세요. `_internal` 폴더를 실행 파일 옆에 그대로 두어야 합니다. Python이나 Tesseract를 별도로 설치할 필요는 없습니다. 수동으로 업그레이드하려면 기존 프로그램을 종료하고 새 폴더에 전체 패키지를 푼 뒤 기존 `data` 폴더를 복사하면 설정을 유지할 수 있습니다.

1. 왼쪽 위의 게임 창 선택 옆에서 대만·한국·일본 서버를 선택해 주세요. 선택한 서버에 맞춰 창 감지가 갱신됩니다. 해당 게임 창을 직접 선택하거나 자동 감지를 사용하세요. 별도 사전 검사나 고정 해상도 설정은 필요하지 않으며 창 크기와 Windows 화면 배율에 맞게 좌표를 변환합니다.
2. 검색할 염색 영역을 켜고 HEX 코드 입력, 색상 선택 또는 화면 스포이트로 목표를 설정해 주세요. 대체 색상도 허용 목표로 인정합니다.
3. 각 영역에 **정확한 HEX** 또는 **유사 색상**을 선택해 주세요. 정확한 HEX는 6자리 코드가 완전히 같아야 하며, 유사 색상은 해당 영역의 허용 색차 ΔE 이내에서 찾습니다.
4. 영역 우선순위를 설정해 주세요. **1이 가장 높은 우선순위**이며 모든 사용 영역의 목표를 충족하는 조합을 항상 우선합니다. 절충이 필요하면 우선순위에 따라 각 영역의 목표 충족 여부와 색차를 차례로 비교합니다. 낮은 순위 영역의 정확한 일치가 높은 순위 영역의 큰 개선보다 우선하지 않습니다. 색차는 ΔE 0.5 단위로 묶어 비교하므로 높은 순위 영역의 미세한 차이 때문에 다음 영역의 개선이 무시되지 않습니다. 유사 모드에서는 허용 색차에 들어온 영역보다 다음 영역의 개선을 우선합니다. 한 영역의 순위를 바꾸면 다른 영역과 자동으로 순위를 맞바꿉니다.
5. **F8** 또는 **검색 시작**을 누르고 안내를 기다린 뒤 게임에서 직접 염색 화면을 열어 주세요. 염색 화면을 연 뒤 시작해도 됩니다. 기본 방식은 **스크린샷 검색**입니다. **정밀 검색**을 선택하기 전에 메모리 읽기 위험 안내를 확인해 주세요.
6. 자동 조작 중에는 게임 창을 활성 상태로 유지하고 되도록 마우스를 조작하지 마세요. 게임 창을 이동하거나 크기를 바꾸지 마세요. **F9**로 언제든 중지하고 마우스를 해제할 수 있습니다. **프로그램은 염색을 자동으로 시작하거나 결과를 적용·확인하지 않습니다.** 게임에서 직접 적용 여부를 결정해 주세요.

팔레트는 해당 염색 세션에 연결됩니다. 여러 영역이 같은 이동·확대·축소·회전을 공유하므로 모든 목표를 동시에 만들 수 없을 수도 있습니다. 계산상 가능한 조합도 실행 가능한 경로와 게임 색상 코드 검증을 통과해야 합니다. 예측 색상이 실제 목표 충족을 뜻하지는 않습니다. 모든 목표를 찾지 못하면 우선순위에 따른 최적 실측 절충 결과를 최대한 유지하며, 절충 결과를 정확한 일치로 표시하지 않습니다.

정밀 색상 검색은 예측 후보를 표시하지 않습니다. 플로팅 창의 **다시 검색 (테스트용)** 또는 **F7**을 누르면 현재 검색을 마치고 휠을 아래로 굴려 팔레트를 최대한 넓게 보이도록 축소한 뒤 같은 염색에서 다시 검색합니다. 재시도는 이번 염색의 남은 시간과 목표 설정을 그대로 사용하며 새 염색약을 소모하지 않습니다. 축소와 재검색을 마칠 시간이 부족하면 현재 색상을 유지합니다. 스크린샷 검색에서는 이번 염색에서 이미 수집한 스크린샷을 재사용합니다. **F9**는 모든 조작을 중지합니다.

이번 팔레트를 처음 인식한 뒤 약 30초 동안 남은 시간 인식값은 참고용입니다. 이후에는 신뢰할 수 있고 연속으로 감소하는 스크린샷 인식값만 실행 종료 시점에 반영합니다. 재시도해도 이 초기 유예 기간이나 염색 시간이 초기화되지 않습니다. 현재 상태를 검증할 수 없으면 과거 색상을 **이전 실측 (현재 미확인)**으로 표시합니다. 게임의 현재 색상을 확인해 주세요.

2영역·3영역 염색 팔레트를 자동 인식합니다. 2영역 염색에서는 실제 왼쪽·오른쪽 영역만 검색하고 메인 창의 영역 3에 **이번 염색에 없음**을 표시합니다. 저장된 설정과 우선순위는 유지됩니다. 존재하지 않는 영역 3만 켜져 있으면 조작을 보내지 않고 영역 1 또는 2를 켜도록 안내합니다.

가죽·목재 등 재질에 기본적으로 순수한 검정이나 흰색이 없으면 `#000000` 또는 `#FFFFFF`를 정확히 찾을 수 없습니다. 게임에 실제 표시되는 색상 코드를 확인해 주세요. 여러 색상을 동시에 정확히 찾는 데 성공한다거나 제한 시간 안에 전체 최적해를 찾는다고 보장하지 않습니다.

## 설정 및 프리셋

- 현재 색상, 대체 색상, 영역 사용 여부, 일치 방식, 허용 색차, 우선순위와 검색 방식은 자동 저장되어 다음 실행 시 복원됩니다.
- 화면 스포이트는 고정된 스크린샷과 마우스의 실제 픽셀 좌표를 일치시킵니다. 게임 창을 이동하거나 강제로 활성화하지 않으며 여러 모니터 환경의 음수 좌표도 지원합니다.
- **프리셋 저장**에서 현재 설정에 이름을 붙여 여러 프리셋으로 보관하고 개별 편집·이름 변경·불러오기·삭제를 할 수 있습니다. 프리셋 편집 내용은 메인 창에 불러와야 현재 설정에 반영됩니다.
- 검색 기록에는 최근 결과 50개와 영역별 색상 코드·ΔE가 저장됩니다. 프리셋과 검색 결과 기록은 별도로 저장됩니다.
- 간체 중국어·번체 중국어·영어·일본어·한국어를 지원합니다. 창 크기를 바꾸면 색상 카드가 1·2·3열로 재배치됩니다. 플로팅 창은 항상 위에 표시되며 게임의 활성 상태를 빼앗지 않고 클릭하거나 드래그할 수 있습니다. 게임 조작을 보내는 동안 잠시 숨었다가 다시 나타납니다.
- 데이터는 기본적으로 프로그램 옆의 `data`에 저장됩니다. 쓰기 권한이 없으면 `%LOCALAPPDATA%\MabinogiMobileColorStudio\data`를 사용하고, 그곳도 사용할 수 없을 때만 시스템 임시 폴더를 사용합니다.
- 진단 기록은 최근 3회분을 보관하며 진행 중인 기록은 임시로 보호합니다. 시스템 임시 폴더의 데이터는 Windows가 삭제할 수 있습니다.

## 문제 해결

게임 프로세스 접근 권한이 부족하다는 안내가 나오면 도구와 게임을 같은 권한 수준으로 실행해 주세요. 게임을 관리자 권한으로 실행 중이면 도구를 오른쪽 클릭하여 **관리자 권한으로 실행**을 선택한 뒤 다시 실행해 주세요. 먼저 게임의 일반 화면에서 재시도하고 권한 확인을 통과한 뒤 새 염색에 들어가세요. 도구가 자체적으로 관리자 권한을 요청하거나 올리지는 않습니다.

실행 중 게임 창의 위치나 크기를 바꾸었다면 중지한 뒤 **F8**로 현재 창을 다시 인식해 주세요. 여러 해상도와 화면 배율을 시험했지만 모든 창 크기, 모니터별로 다른 배율이나 게임 버전에 대한 실기기 검증을 완료한 것은 아닙니다. 한국·일본 서버는 계속 테스트 중입니다.

문제가 발생하면 [GitHub Issues](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/issues)에 이번 로그를 첨부해 주세요. 제보를 위해 염색 아이템을 반복해서 소모할 필요는 없습니다. 최종 결과는 게임의 현재 색상 코드로 확인해 주세요.

## 업데이트

업데이트 기능이 있는 버전에서는 메인 창에서 GitHub의 새 버전을 확인하고 **사용자가 다운로드와 설치 여부를 선택**합니다. 변경된 파일을 기준으로 업데이트하며 설정·프리셋과 `data` 전체를 보존합니다. 업데이트 기능이 없는 이전 버전은 처음 한 번 전체 패키지로 수동 업그레이드해야 합니다.

인터넷에 연결할 수 없을 때는 `UPDATE-ONLY-ColorStudio-0.4.4-win-x64.zip`을 도구의 오프라인 업데이트 가져오기에서 사용해 주세요. **업데이트 전용 패키지이므로 처음 설치하거나 직접 압축을 풀어 실행하는 용도가 아닙니다.** 공식 0.4.3에서 0.4.4으로 업데이트할 때는 더 작은 증분 패키지 `UPDATE-ONLY-ColorStudio-from-0.4.3-to-0.4.4-win-x64.zip`도 사용할 수 있습니다. 처음 설치할 때는 전체 휴대용 패키지를 사용해 주세요. 자세한 내용은 [업데이트 안내](docs/automatic-updates.md)를 참고해 주세요.

## 개발 및 테스트

Windows 10/11, Python 3.12를 사용합니다. 제품 소스는 `work/studio`에 있습니다.

```powershell
python -m pip install -r requirements-build.txt
python work/studio/app.py
python scripts/run_tests.py
python scripts/run_tests.py --suite release
```

기본 빠른 테스트는 현재 제품의 동작 요구사항을 검증합니다. 릴리스 테스트에는 저장된 실제 팔레트의 검색과 복귀 검증이 추가됩니다. 과거 연구와 대규모 검색 조합은 `--suite research` 또는 `--suite full`로 실행할 수 있습니다. [테스트 안내](TESTING.md)에서 자세한 내용을 확인해 주세요. 결과에는 통과·건너뜀·실패·오류 및 소요 시간이 표시됩니다. 테스트 구성은 실제 검색 능력이나 게임 시간 한도를 바꾸지 않습니다.

소스 실행 및 패키징에는 Tesseract OCR과 `eng.traineddata`가 필요합니다. 기본 경로는 `C:/Program Files/Tesseract-OCR`이며 `TESSERACT_HOME`으로 변경할 수 있습니다. OCR 언어는 UI 언어와 별개입니다.

```powershell
python work/studio/build_release.py
```

빌드 결과는 `outputs/release/ColorStudio` 전체 폴더입니다. 개인 설정·세션·스크린샷은 배포 패키지나 Git에 포함하지 않습니다. 현재 검증 범위는 [검증 기록](work/studio/VERIFICATION.md), 버전별 변경 사항은 GitHub Release에서 확인해 주세요.
