# 염색 공방 · 마비노기 모바일

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

**ColorStudio 0.4.10**는 마비노기 모바일 대만 서버를 지원하는 Windows용 색상 검색 도구입니다. 한국·일본 서버는 테스트 중입니다. 설정한 목표 색상에 맞춰 팔레트를 조작하며, 결과를 적용할지는 게임에서 직접 결정합니다.

## 1. 설치

[GitHub Releases](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/releases)에서 **`ColorStudio-v0.4.10-Windows-x64.zip`**을 받아 전체 압축을 푼 뒤 `ColorStudio.exe`를 실행하세요. `_internal` 폴더는 실행 파일 옆에 그대로 두세요. Python이나 Tesseract를 따로 설치할 필요는 없습니다.

## 2. 색상 검색 시작

1. **서버와 게임 창**을 선택하세요. 고정 해상도는 필요하지 않습니다. 창 위치와 크기는 시작 전에 조정하세요.
2. 검색할 **염색 영역**을 켜고 목표 색상, 일치 조건, 우선순위를 설정하세요. HEX 입력, 색상 선택, 스포이트를 사용할 수 있습니다. 대체 색상도 허용 목표입니다. 우선순위 1이 가장 높습니다.
3. **F8 / 검색 시작**을 누르고 안내에 따라 게임의 염색 화면을 여세요. 팔레트를 먼저 연 뒤 도구를 시작해도 됩니다.
4. 자동 조작 중에는 게임을 맨 앞에 두고 마우스를 움직이거나 게임 창을 변경하지 마세요. 결과는 게임에서 직접 적용합니다.

**검색 방식**과 각 영역의 **일치 조건**은 서로 다른 설정입니다.

| 설정 | 선택 항목 | 용도 |
|---|---|---|
| 검색 방식 | 스크린샷 검색(기본) | 스크린샷과 마우스 조작을 사용하며 게임 메모리를 읽지 않습니다 |
| 검색 방식 | 정밀 검색 | 게임 메모리를 읽어 팔레트 조작을 계획합니다 |
| 일치 조건 | 완전 일치(HEX) | 6자리 색상 코드가 같은 색을 찾습니다 |
| 일치 조건 | 유사 색상 | 영역별 허용 색차로 찾습니다. 값이 작을수록 목표에 가까운 색이어야 합니다 |

스크린샷 검색의 위험도는 상대적으로 낮습니다. 정밀 검색은 게임 메모리를 읽어 탐지나 계정 제재 위험이 더 큽니다. 스크린샷과 자동 마우스 조작도 계정 안전을 보장하지는 않습니다.

활성화한 모든 영역이 조건을 만족하는 조합을 우선 찾고, 대안을 고를 때는 설정한 우선순위로 비교합니다. 두 영역 팔레트에서는 없는 세 번째 영역을 자동으로 제외하며 저장된 설정은 변경하지 않습니다.

## 3. 결과 확인

- **목표 달성**: 게임에서 읽은 영역별 실제 색상 코드를 확인한 뒤 적용 여부를 결정하세요.
- **일부 목표 미달성**: 현재 색상과 영역별 색차를 확인하고 조정, 재검색 또는 결과 사용을 선택하세요.
- **마지막 실측(현재 상태 미확인)**: 이전에 읽은 색상입니다. 현재 게임 화면을 확인하세요.

모든 목표를 충족하지 못하면 영역 우선순위에 따라 전체 색차뿐 아니라 색상 계열과 채도도 고려해 목표 색감에 가까운 절충 배색을 고릅니다. 표시되는 색차, 유사 색상의 허용 색차, 완전 일치(HEX)의 충족 조건은 바뀌지 않습니다.

계산 중에는 팔레트가 잠시 움직이지 않을 수 있습니다. 플로팅 창에서 현재 단계와 읽은 색상을 확인할 수 있습니다.

색상, 일치 조건, 우선순위는 자동 저장됩니다. **프리셋 저장**으로 설정에 이름을 붙여 보관하고 편집·불러오기·삭제할 수 있습니다. 편집한 프리셋을 현재 검색에 사용하려면 불러와야 합니다. 검색 기록과 설정 프리셋은 따로 저장합니다.

## 4. 중지와 재검색

- **F9 / 중지**: 자동 조작을 끝냅니다. 게임에서 현재 색상을 확인하세요.
- **F7 / 재검색(테스트용)**: 팔레트를 축소하고 같은 염색 회차의 남은 시간과 목표 설정으로 다시 검색합니다. 제한 시간은 초기화되지 않으며 염색 아이템을 추가로 사용하지 않습니다.

도구는 염색 화면을 자동으로 열거나 결과를 자동으로 확정·적용·취소하지 않습니다.

## 5. 업데이트

메인 화면에서 **업데이트 확인**을 누르고 새 버전이 있으면 **업데이트 다운로드**를 선택하세요. 다운로드가 끝나면 **설치 후 다시 시작**을 누릅니다. 설정·프리셋·기록은 유지됩니다.

업데이트 파일은 먼저 미러를 통해 받고, 미러를 사용할 수 없으면 자동으로 GitHub에 직접 연결합니다. 모든 파일은 서명과 해시로 검증됩니다. 온라인 업데이트를 할 수 없으면 전체 패키지로 수동 업그레이드하고 `data`를 유지하세요.

## 도움말과 문제 제보

- **게임 창을 찾을 수 없음**: 게임을 실행하고 해당 서버를 선택한 뒤 창 목록을 새로 고치세요.
- **권한 부족**: 게임과 도구를 같은 권한으로 실행하세요. 게임이 관리자 권한으로 실행 중이라면 도구도 관리자 권한으로 다시 여세요.
- **창 이동 또는 크기 변경**: F9로 중지한 뒤 F8로 현재 창을 다시 인식하세요.
- **문제 제보**: [GitHub Issues](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/issues)에 이번 로그를 첨부하세요. 제보를 위해 염색 아이템을 다시 사용할 필요는 없습니다.

데이터는 보통 실행 파일 옆의 `data`에 저장합니다. 쓰기가 불가능하면 `%LOCALAPPDATA%\MabinogiMobileColorStudio\data`를 사용하며, 필요한 경우 임시 폴더를 사용합니다. 수동으로 옮길 때는 실제 사용 중인 데이터 폴더를 복사하세요.
