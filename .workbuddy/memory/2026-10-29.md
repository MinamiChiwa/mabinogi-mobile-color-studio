## V7 界面迁移到 Qt：按原型对齐 + 建立验证

**背景**：`docs/design/prototype-region-color-v7.html` 是界面基准；`work/studio/qt_ui` 的
Qt 实现此前按 `ui-spec-v7.md` 写，与原型有明显偏差。本轮把 QML 拉回与原型一致。

### 关键设计基准（原型实测，1280×800）
- 页：`padding 16/24/18`，app `gap 9`，内容宽 `min(1400,100%)`
- 顶栏 44 / 环境条 50（内边距 8）/ 说明行 14 / 卡片 **481** / 运行栏 **120** / 页脚 14
- 卡片：`padding 14/16`、radius 10、1px `--line`；**不做整卡染色**（底色 = `panel`）
- 卡片行序：`区域 N · 启用 · 开关 ‖(右) 优先级 · 下拉` → 目标色 → 颜色要求(无行首标签) →
  容差(带 56px 标签) → 替代色 → 目标色集合(688:265) → 读数
- 读数：`当前 —` / `实测 —  ΔE — [徽标]`，徽标 达标/未达标/未开始/未参与
- 断点：>980 三列、≤980 单列(≤620)、≤1180 隐藏「交互演示」、≤560 顶栏与环境条各两行

### Qt 侧的三个接线坑（都已验证）
1. 上下文属性必须叫 `uiState`（`state` 是 Qt Quick Item 内置属性，会被遮蔽）
2. 卡片桥接属性必须叫 `uiBridge`——`bridge: bridge` 是自引用绑定 → undefined，
   症状是卡内所有交互静默失效
3. `QtHost` 继承顺序 `Business` 必须在 `QObject` 之前

### 两个被验证脚本抓到的真实缺陷
- 上面第 2 条（自引用绑定）
- `business.handle_event` 曾是被裁剪的副本，缺 `atlas_*/screenshot_result/worker_failed/
  action/best/search` 等 12 类分支 → 已用原版全文替换

### 交付
- `docs/design/qt-migration.md`（模块对应表 / 结构 / 依赖构建 / 验证 / 零改动证据）
- `verify_qt.py`：A 环境 12、B 业务零改动 14、C 界面加载 6、D 交互 7、E 断点 4、F 浮窗 3
  = **46 项全通过**；`--shots` 出图到 `docs/design/qt-screenshots/`
- 打包：`COLOR_STUDIO_UI=qt python work/studio/build_release.py`；`run_qt.py` 已支持 frozen 路径

### 结论/教训
- 「零改动」要用 **AST 比对**证明，不能靠肉眼看代码——原版 app.py 是压缩排版，
  文本比对必然全红；AST 比对能精确圈出 4 处必要接缝（go / 2×autosave / hotkey_loop）
- QML 布局出问题时先量 `implicitHeight`：`ColumnLayout` 在高度不足时会压缩各行，
  表现为文字互相压住；根因是 `Layout.topMargin` 与 `implicitHeight` 重复计入


## V2：锚定浮层 + 统一动效 + 紧凑布局（同日晚）

**用户要求**：点击色块/目标色集合要按屏幕位置动态弹出；所有点击要有过渡动画；
补齐原版功能；按钮与整体高度要压缩；修正对齐。

### 实现要点
- `Popover.qml`：通用锚定浮层（Item 自绘，非 Controls Popup —— Popup 的 x/y/scale
  动画不可控）。可用区 = 窗口 ∩ 屏幕可用区；方向优先级 below→right→above→left，
  都放不下时选空间最大的一侧。浮层 parent 到 `Window.contentItem`，不参与卡片布局。
- 色板：`InlineColorPicker` 变成无边框内容（`framed: false`），装进 Popover；
  目标色集合：新增 `AtlasPanel.qml`（full_atlas 按需生成 data URI），浮层里保留
  「在窗口中打开」→ 原 Viewer（带悬停读色）。
- 显示由状态驱动：`card.pickerOpen` / `card.atlasOpen` → Popover show/close，
  因此脚本、快捷键、点击三种入口都能打开。
- 动效统一：窗口淡入 150、浮层 190、按钮 0.975、下拉 0.97、分段指示块 190、
  容差行 220、开关 180。

### 尺寸（V2 单一来源，Main.qml 顶部常量）
顶栏 40 / 环境条 46 / 说明 12 / 运行栏 108 / 页脚 12 / 卡片 = 窗口高 - 其余（下限 448）
卡片内：padding 12/14、head 34、目标色行 12+32、模式行 10+1+12+26、容差 8+16、
替代色 10+20、色图 12+1+12+14+5+缩略图、读数 10+1+15+5+15（合计 438）。

### 这一轮修掉的两个真 bug
1. **色板缩略图不重算**：QtCard 的 setter 只 `refresh()`，没走 `preview()`；
   补 80ms 防抖 + `preview()/schedule_palette()`（与 Tk 的 trace 行为一致）。
2. **方案对话框是只读表单**，且保存走 `_collect()`（当前设置）而不是编辑内容；
   补启用/优先级/颜色要求/容差/替代色/寻色方式，新增 `PresetBridge.saveProfile()`。

### 验证
`verify_qt.py` 增至 **54 项**（新增 G 组 8 项：浮层弹出/不越界/方向/关闭/集合浮层/模式切换）。
脚本改用临时 `business.DATA`，不再污染用户 `data/profile.json`。


## V3：浮层滑出 / 色图铺满 / 语言完整切换 / 全窗口滑动出场（同日晚）

**用户反馈的 5 个问题**
1. 深浅模式按钮没对齐 → 它直接挂在 `Row` 上（贴顶），旁边按钮包在 30 高 Item 里垂直居中，
   差 5px。包一层 Item + `anchors.verticalCenter` 解决。
2. 目标色集合窗口固定向下、颜色留黑边 → Popover 记录「锚点中心 - 面板中心」向量，
   关闭态停在该向量上，打开时滑到目标位；AtlasPanel 去掉 fitScale，图片铺满可视区。
3. 缩略图圆角像直角 → 容器 6→12；关键：`Rectangle.clip` 只裁矩形，图片铺进去仍是直角。
   `MultiEffect.maskSource` 在这个窗口结构下实测无输出（单独测试可用，主窗口不行），
   改为 Python 生成 PNG 时烘焙 alpha 圆角（`core._round_corners`，半径按 min(w,h)//3 夹紧）。
4. 无法添加替代色 → `UiField.onTextEdited` 只发信号没回写 `field.text`，外层读到的永远是空串。
   补回写 + `Connections` 同步；bridge 增加 `validHex` / `removeAlt`（复用 `normalize_hex`）；
   色块 hover 出现 ×，点击删除。
5. 语言切换残留中文 → 见下。

**语言方案（Qt 版与 Tk 不同）**
- `Loc.qml`（qmldir 注册 singleton）`Loc.t(s)` → `uiState.tr()` → `qt_ui/i18n_qt.py::translate()`；
  `t()` 内读 `uiState.language`，使每个文案绑定都依赖该属性，切语言自动重算。
- `i18n_qt.EXTRA` 只补 Qt 新增短标签（85 个 QML 字面量），其余回退原作者 `i18n` 词典。
- Python 侧只存简体原文：`_TextSink` 用 `getattr(text,'source',text)`；顶栏/工具栏/服务器
  列表直接存原文；`UiCombo` 显示时翻译、回调仍回传原文。
- 例外：寻色方式下拉存「当前语言短名」，因为 `business.change_search_strategy` 内部比较
  `tr('精准寻色')`。
- 单复数：键带 `（单）` 标记，英文单独映射；`translate()` 最后统一去掉标记，避免中文显示出来。

**窗口出场**
`qt_ui/window_fx.py`：`place()` 居中到父窗口并夹进屏幕可用区；`direction_for()` 按窗口中心
在上半/下半屏决定 from-top / from-bottom；`present()` = place + 滑入 210ms。所有对话框 QML
改 `visible: false`，由 present() 定位后再 show；Overlay 也走 slide_in。

**验证**：`verify_qt.py` 68 项全过；新增 H（语言无残留，允许「南千和」）、I（替代色增删）、
J（滑动方向/夹边/锚点）。`run_tests.py --suite smoke` 56 项全过。
