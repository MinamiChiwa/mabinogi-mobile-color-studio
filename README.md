# 染色工坊 · 瑪奇 Mobile

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

**ColorStudio 0.4.10** 是 Windows 自动寻色工具，支持台服，韩服和日服仍在测试中。工具按您设置的目标颜色操作色板，结果由您在游戏内手动确认。

## 1. 安装

从 [GitHub Releases](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/releases) 下载 **`ColorStudio-v0.4.10-Windows-x64.zip`**，完整解压后运行 `ColorStudio.exe`。保留旁边的 `_internal` 文件夹，无需另装 Python 或 Tesseract。

## 2. 开始寻色

1. 选择**服务器与游戏窗口**。无需设置固定分辨率；请先调整好窗口，再开始。
2. 启用需要匹配的**颜色区域**，设置目标色、匹配要求与优先级。可输入 HEX、选色或使用屏幕吸管；替代色也属于允许的目标。优先级 1 最高。
3. 按 **F8／开始寻色**，根据提示进入游戏染色界面；已经打开色板时也可以启动工具。
4. 自动操作期间保持游戏在前台，避免移动鼠标或改变游戏窗口。最后在游戏内决定是否套用。

**寻色方式**与**颜色要求**是两个不同设置：

| 设置 | 选项 | 用途 |
|---|---|---|
| 寻色方式 | 截图寻色（默认） | 使用截图和鼠标操作，不读取游戏内存 |
| 寻色方式 | 精准寻色 | 读取游戏内存后规划操作 |
| 颜色要求 | 精准 HEX | 六位色码完全一致 |
| 颜色要求 | 相似颜色 | 在该区域设置的色差范围内匹配；数值越小越接近目标 |

截图寻色的风险相对较低。精准寻色读取游戏内存，风险较高，可能触发检测或账号处罚；截图与自动鼠标操作也不是账号安全保证。

工具优先寻找全部启用区域达标的组合，需要妥协时按您设置的优先级比较。双区域色板会自动停用不存在的第三区域，不改动其已保存设置。

## 3. 看结果

- **目标达标**：查看各区域游戏实际色码，在游戏内手动确认是否套用。
- **未全部达标**：查看当前颜色与各区域色差，再决定继续调整、重试或使用该结果。
- **上次实测（当前未确认）**：这是之前读取的颜色，请查看游戏当前画面。

未全部达标时，工具按区域优先级选择妥协颜色，同时考虑整体色差、色相与饱和度，尽量保留目标的颜色特征。显示的色差、相似颜色的容差和精准 HEX 的达标条件不变。

计算阶段色板可能暂时不动；浮窗会显示所处阶段和已读取的颜色。

颜色、匹配要求和优先级自动保存。**保存方案**可给当前设置命名，保存多套方案；编辑后需载入才会用于当前寻色。寻色记录与设置方案分别保存。

## 4. 停止与重试

- **F9／停止**：结束自动操作，然后在游戏中查看当前颜色。
- **F7／重新寻色（仅供测试）**：缩小色板后，在同一局重新搜索。沿用本局剩余时间和目标设置，不会重置倒计时或额外使用染色剂。

工具不会自动开启染色，也不会自动确认、套用或取消结果。

## 5. 更新

主界面点击**检查更新**，发现新版本后选择**下载更新**，下载完成再点击**安装并重启**。更新保留设置、方案与记录。

更新文件优先经镜像站下载，镜像不可用时自动直连 GitHub；所有文件都经过签名与哈希校验。无法在线更新时，用完整包手动升级并保留 `data`。

[在线与手动更新指南](docs/automatic-updates.md) · [0.4.10 更新内容](docs/release-notes-0.4.10.md)

## 帮助与反馈

- **找不到窗口**：启动游戏，选择对应服务器后刷新窗口列表。
- **权限不足**：让工具和游戏使用相同权限；游戏以管理员运行时，可用管理员权限重开工具。
- **窗口已移动或调整大小**：按 F9 停止，再按 F8 按当前窗口重新识别。
- **反馈问题**：在 [GitHub Issues](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/issues) 附本次日志，无需为反馈重复使用染色剂。

数据通常保存在程序旁的 `data`；目录不可写时使用 `%LOCALAPPDATA%\MabinogiMobileColorStudio\data`，必要时使用临时目录。手动迁移时请复制实际使用的数据目录。
