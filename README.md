# 染色工坊 · 瑪奇 Mobile

作者：**南千和** · [爱发电](https://afdian.com/a/minamichiwa) · [Patreon](https://patreon.com/chiwaminami)

Windows 自动寻色工具，支持瑪奇 Mobile 台服、韩服、日服的已适配客户端版本；韩服、日服仍在测试中。默认截图寻色使用原始截图采样、图像定位及游戏实际 HEX 复核，规划平移、缩放和旋转，不读取游戏内存。精准寻色仍可手动选择，会直接读取游戏进程内存。服务器适配范围见[服务器说明](docs/server-adaptation/server-selection.md)。

推荐使用截图寻色：不读取游戏内存，风险相对较低。精准寻色读取游戏内存，风险较高，可能触发游戏检测或账号处罚。截图和自动鼠标操作也不保证账号安全，请自行评估是否使用。赞助完全自愿，不影响功能。本工具由 AI 辅助开发。

## 使用

解压完整发布包，运行 `ColorStudio.exe`。保留 `_internal` 文件夹；无需安装 Python 或 Tesseract。升级前退出旧程序，解压到新目录，需要保留设置时将旧目录的 `data` 复制过去。

1. 在游戏窗口选项旁选择台服、韩服或日服，窗口检测会同步更新。选择对应窗口或使用自动检测；无需额外预检或固定游戏分辨率，支持窗口尺寸及 Windows 缩放的坐标适配。
2. 启用需要匹配的区域，设置目标 HEX、选色或使用吸管。替代颜色同样视为可接受目标。
3. 每个区域选择精准 HEX 或相似颜色。精准要求六位色码完全一致；相似按该区域的 ΔE 容差判断。
4. 设置区域优先级，1 最高。始终先寻找全部启用区域达标的组合；没有全达标方案时，按优先级逐区比较是否达标与色差。色差按 ΔE 0.5 分档，避免高优先级的极小差异掩盖后续区域的明显改善；精准达标仍要求 HEX 完全一致。调整优先级会自动交换另一区域的顺序。
5. 按 **F8** 或开始，等待提示后手动进入染色。也可进入染色界面后启动工具。默认使用“截图寻色”；若选择“精准寻色”，请先了解按钮上的内存读取风险提示。
6. 操作期间保持游戏前台，不移动鼠标或调整游戏窗口。**F9** 随时停止并释放鼠标。是否套用结果由您在游戏内手动确认。

色板与目标会话绑定。多区域共享操作变换，数学色板候选需要可执行路线及游戏色码复核；预测颜色不代表实际达标。未达标时尽量保留按优先级排序的最佳实测妥协结果，不把妥协称为精准命中。

精准模式不显示预测候选。点击浮窗「重新寻色」或按 **F7** 可结束当前搜索，向下滚轮缩小画板至最大可见范围后，在同一局重新搜索。重试沿用本局剩余时间和目标设置，不消耗新道具；不足以完成缩小与新搜索时保留当前颜色。**F9** 仍停止全部操作。

首次发现本局色板后的约 30 秒内，倒计时仅作参考；随后只有可靠、连续递减的截图读数才调整执行截止。重试不会重置宽限或局内时间。当前状态无法复核时，历史颜色标为「上次实测（当前未确认）」，请以游戏当前颜色为准。

自动适配游戏中的双区域和三区域色板。双区域局只匹配左、右两个实际区域，主界面第三区域标记“本局不可用”，不会改变其保存设置或优先级。仅启用不存在的第三区域时不发送操作，并提示启用区域 1 或 2。

皮革、木材等材质的基础色不含纯黑或纯白时，无法精准抓取 `#000000` 或 `#FFFFFF`。请以游戏内实际色码为准。多色精准抓取不能保证成功率，也不保证有限时间内找到全局最优解。

## 设置与方案

- 当前颜色、替代色、启用区域、匹配模式、容差、优先级和寻色方式自动保存，下次启动恢复。
- 屏幕吸管使用冻结截图和物理鼠标坐标一一对应，不改变游戏窗口位置或强制切换游戏前台；支持虚拟桌面的负坐标原点。
- “保存方案”管理多套命名配置：保存当前配置，独立编辑或重命名，载入与删除。编辑方案不会立即改动主界面，载入后才生效。
- 寻色记录保留最近 50 次结果，显示各区色码和 ΔE；设置方案与寻色结果记录分别保存。
- 界面支持简体中文、繁體中文、English、日本語及 한국어，窗口可调整尺寸。颜色卡片按一、二、三列重排；浮窗置顶，平时可点击和拖动且不抢游戏焦点，实际发送游戏动作时短暂隐藏避让，随后恢复。
- 数据默认存于程序旁 `data`；不可写时改用 `%LOCALAPPDATA%\MabinogiMobileColorStudio\data`，再失败时才使用系统临时目录。
- 诊断记录保留最近三次，活动记录暂时保护。系统临时目录可能被系统清理。

## 诊断

启动程序后直接选择服务器与游戏窗口，无需额外预检脚本。不同屏幕与缩放已有测试；运行中改变窗口位置或尺寸后，请停止并重新开始。客户端更新后可能需要重新适配。

提示进程访问权限不足时，让工具和游戏使用相同权限级别；游戏以管理员运行时，可右键工具“以管理员身份运行”后重开。工具不会自动提升权限。

遇到问题请在 [GitHub Issues](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/issues) 附本次日志，不必为反馈重复消耗道具。最终以游戏当前色码为准。

## 开发与测试

Windows 10/11，Python 3.12。生产源码在 `work/studio`。

```powershell
python -m pip install -r requirements-build.txt
python work/studio/app.py
python scripts/run_tests.py
python scripts/run_tests.py --suite release
```

默认快速集合覆盖当前产品合同；发布集合增加实际保存色板的搜索与回退测试。历史研究和大搜索矩阵仍可用 `--suite research` 或 `--suite full` 运行。详见 [测试说明](TESTING.md)。输出会区分通过、跳过、失败及错误，并记录耗时。测试精简不改变生产搜索能力或游戏时间预算。

源码运行和打包需 Tesseract OCR 及 `eng.traineddata`，默认 `C:/Program Files/Tesseract-OCR`，可设置 `TESSERACT_HOME`。OCR 语言独立于界面语言。

```powershell
python work/studio/build_release.py
```

产物为 `outputs/release/ColorStudio` 完整目录。个人配置、会话和截图不进入发布包或 Git。当前验证范围见 [验证记录](work/studio/VERIFICATION.md)，版本变化见 GitHub Release。

## 自动更新

具备更新器的引导版本可在主界面检查 GitHub 更新，经用户决定下载和安装。按文件差异下载，保留设置、方案和全部 data；网络不通时可导入完整离线更新包。旧版需要首次手动升级。0.4.3 正式包已配置更新签名；重新寻色按钮标记为「仅供测试」。详见 [更新说明](docs/automatic-updates.md)。

首次安装下载 `ColorStudio-v0.4.4-Windows-x64.zip`。`UPDATE-ONLY-ColorStudio-0.4.4-win-x64.zip` 仅用于工具内“导入离线更新”，不能直接解压运行；`UPDATE-ONLY-ColorStudio-from-0.4.3-to-0.4.4-win-x64.zip` 仅适用于官方 0.4.3。
