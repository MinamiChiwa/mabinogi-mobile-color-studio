# 染色工坊 · 瑪奇 Mobile

作者：**南千和** · [愛發電](https://afdian.com/a/minamichiwa) · [Patreon](https://patreon.com/chiwaminami)

Windows 自動尋色工具，適用於港澳台服瑪奇 Mobile。預設精準尋色讀取本局色板，規劃平移、縮放與旋轉，並核對遊戲色碼。圖像尋色作為精準尋色故障時的備用方式。

遊戲中使用工具可能存在風險，建議謹慎使用。贊助完全自願，不影響功能。本工具由 AI 輔助開發。

## 使用

解壓完整發布包，執行 `ColorStudio.exe`。保留 `_internal` 資料夾；無需安裝 Python 或 Tesseract。升級前結束舊程式，解壓到新目錄，需要保留設定時將舊目錄的 `data` 複製過去。

1. 選擇遊戲視窗，只有一個視窗時可自動偵測。無需固定遊戲解析度，支援視窗尺寸及 Windows 縮放的座標適配。
2. 啟用需要比對的區域，設定目標 HEX、選色或使用吸管。替代顏色同樣視為可接受目標。
3. 各區域選擇精準 HEX 或相似顏色。精準要求六位色碼完全一致；相似依該區域的 ΔE 容差判斷。
4. 設定區域優先順序，1 最高。始終先尋找全部啟用區域達標的組合；沒有全達標方案時，依優先順序滿足區域目標，再降低色差。調整優先順序會自動交換另一區域的順序。
5. 按 **F8** 或開始，等待提示後手動進入染色。也可進入染色畫面後啟動工具。預設使用精準尋色；圖像尋色僅在其故障時使用。
6. 操作期間保持遊戲前景，不移動滑鼠或調整遊戲視窗。**F9** 隨時停止並釋放滑鼠。是否套用結果由您在遊戲內手動確認。

色板與目標會話綁定。多區域共享操作變換，數學色板候選需要可執行路線及遊戲色碼複核；預測顏色不代表實際達標。未達標時盡量保留依優先順序排序的最佳實測折衷結果，不將折衷稱為精準命中。

找到目標後仍會保留其他候選，依區域優先順序與色差排序。時間允許時自動定位目標並核對實際色碼；您可在浮窗選擇另一方案。每次切換會重新核對本局狀態、完整路線與返回餘量，時間不足時保持目前顏色。未執行候選標為預測，不能當作實測結果。結束後可從主畫面「查看本局候選」開啟唯讀清單。

自動適配遊戲中的雙區域及三區域色板。雙區域局僅比對左、右兩個實際區域，主畫面第三区域標記「本局無法使用」，不改變已儲存設定或優先順序。僅啟用不存在的第三区域時不傳送操作，並提示啟用區域 1 或 2。

皮革、木材等材質的基礎色不含純黑或純白時，無法精準抓取 `#000000` 或 `#FFFFFF`。請以遊戲內實際色碼為準。多色精準抓取無法保證成功率，也不保證有限時間內找到全域最優解。

## 設定與方案

- 目前顏色、替代色、啟用區域、比對模式、容差、優先順序與尋色方式會自動儲存，下次啟動恢復。
- 「儲存方案」管理多套命名設定：儲存目前設定，獨立編輯或重新命名，載入與刪除。編輯方案不會立即改動主畫面，載入後才生效。
- 尋色紀錄保留最近 50 次結果，顯示各區色碼與 ΔE；設定方案與尋色結果紀錄分別儲存。
- 介面支援簡體中文、繁體中文及 English，視窗可調整尺寸。顏色卡片依一、二、三列重排；浮窗置頂，自動執行期間透傳滑鼠，候選選擇期間可點擊且不搶遊戲焦點。
- 資料預設位於程式旁的 `data`；不可寫入時改用 `%LOCALAPPDATA%\MabinogiMobileColorStudio\data`，再失敗時才使用系統暫存目錄。
- 診斷紀錄保留最近三次，活動紀錄暫時保護。系統暫存目錄可能被系統清理。

## 診斷

執行 `native-window-check.ps1` 可在普通遊戲畫面做無輸入預檢，無需染色道具。使用 Windows PowerShell 開啟腳本，或依同目錄 `WINDOW_CHECK.zh-TW.md` 操作。

預檢涵蓋目前遊戲版本、模組、實體客戶區與遊戲內部座標；預檢通過不等同於一次真實染色精度驗證。不同螢幕與縮放已有測試，但不宣稱所有尺寸、混合 DPI 及遊戲版本都經過實機驗收。執行中改變視窗位置或尺寸後，請停止並重新開始。

提示程序存取權限不足時，讓工具與遊戲使用相同權限層級；遊戲以管理員執行時，可右鍵工具選擇「以系統管理員身分執行」後重開。先在普通畫面執行預檢，不必開新染色局。工具不會自動提升權限。

遇到問題請在 [GitHub Issues](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/issues) 附本次紀錄，不必為回報重複消耗道具。最終以遊戲目前色碼為準。

## 開發與測試

Windows 10/11，Python 3.12。正式原始碼位於 `work/studio`。

```powershell
python -m pip install -r requirements-build.txt
python work/studio/app.py
python scripts/run_tests.py
python scripts/run_tests.py --suite release
```

預設快速集合涵蓋目前產品契約；發布集合增加保存色板的搜尋與回復測試。歷史研究及大型搜尋矩陣仍可使用 `--suite research` 或 `--suite full`。詳見 [測試說明](TESTING.md)。輸出分別記錄通過、略過、失敗、錯誤及耗時。測試精簡不改變實際搜尋能力或遊戲時間預算。

原始碼執行與封裝需要 Tesseract OCR 及 `eng.traineddata`，預設 `C:/Program Files/Tesseract-OCR`，可設定 `TESSERACT_HOME`。OCR 語言獨立於介面語言。

```powershell
python work/studio/build_release.py
```

產物為 `outputs/release/ColorStudio` 完整目錄。個人設定、會話及截圖不進入發布包或 Git。目前驗證範圍見 [驗證紀錄](work/studio/VERIFICATION.md)，版本變更見 GitHub Release。
