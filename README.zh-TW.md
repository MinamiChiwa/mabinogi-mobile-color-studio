# 染色工坊 · 瑪奇 Mobile

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

**ColorStudio 0.4.5** 是 Windows 自動尋色工具，支援台服，韓服與日服仍在測試中。工具依您設定的目標顏色操作色板，結果由您在遊戲內手動確認。

## 1. 安裝

從 [GitHub Releases](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/releases) 下載 **`ColorStudio-v0.4.5-Windows-x64.zip`**，完整解壓縮後執行 `ColorStudio.exe`。請保留旁邊的 `_internal` 資料夾，不必另裝 Python 或 Tesseract。

**`UPDATE-ONLY` 是更新專用套件，不能用來首次安裝，也不能直接解壓縮執行。** 已安裝的使用者請看下方「更新」。

## 2. 開始尋色

1. 選擇**伺服器與遊戲視窗**。不必設定固定解析度；請先調整好視窗，再開始。
2. 啟用要比對的**顏色區域**，設定目標色、比對要求與優先順序。可輸入 HEX、選色或使用螢幕滴管；替代色也屬於允許的目標。優先順序 1 最高。
3. 按 **F8／開始尋色**，依提示進入遊戲染色畫面；色板已開啟時也可以啟動工具。
4. 自動操作時保持遊戲在前景，避免移動滑鼠或改變遊戲視窗。最後在遊戲內決定是否套用。

**尋色方式**與**顏色要求**是兩個不同設定：

| 設定 | 選項 | 用途 |
|---|---|---|
| 尋色方式 | 截圖尋色（預設） | 使用截圖與滑鼠操作，不讀取遊戲記憶體 |
| 尋色方式 | 精準尋色 | 讀取遊戲記憶體後規劃操作 |
| 顏色要求 | 精準 HEX | 六位色碼完全一致 |
| 顏色要求 | 相似顏色 | 在該區域設定的色差範圍內比對；數值越小越接近目標 |

截圖尋色的風險相對較低。精準尋色會讀取遊戲記憶體，風險較高，可能觸發偵測或帳號處分；截圖與自動滑鼠操作也不保證帳號安全。

工具優先尋找全部啟用區域達標的組合，需要折衷時依您設定的優先順序比較。雙區域色板會自動停用不存在的第三區域，不改動已儲存的設定。

## 3. 看結果

- **目標達標**：查看各區域的遊戲實際色碼，在遊戲內手動確認是否套用。
- **未全部達標**：查看目前顏色與各區域色差，再決定繼續調整、重試或使用結果。
- **上次實測（目前未確認）**：這是先前讀取的顏色，請查看遊戲目前畫面。

計算時色板可能暫時不動；浮窗會顯示目前階段及已讀取的顏色。

顏色、比對要求及優先順序會自動儲存。**儲存方案**可為目前設定命名，保留多套方案；編輯後須載入才會用於目前尋色。尋色紀錄與設定方案分開儲存。

## 4. 停止與重試

- **F9／停止**：結束自動操作，接著在遊戲內查看目前顏色。
- **F7／重新尋色（僅供測試）**：縮小色板後，在同一局重新搜尋。沿用剩餘時間及目標設定，不重設倒數，也不額外使用染色劑。

工具不會自動開啟染色，也不會自動確認、套用或取消結果。

## 5. 更新

在主畫面點選**檢查更新**，發現新版本後選擇**下載更新**，完成後再按**安裝並重新啟動**。更新會保留設定、方案及紀錄。

無法連線至 GitHub 時，下載 `UPDATE-ONLY-ColorStudio-0.4.5-win-x64.zip`，在工具內選擇**匯入離線更新**。首次安裝仍使用完整套件。

## 協助與回報

- **找不到視窗**：啟動遊戲，選取對應伺服器後重新整理視窗清單。
- **權限不足**：讓工具與遊戲使用相同權限；遊戲以系統管理員執行時，可用相同權限重新開啟工具。
- **視窗已移動或調整大小**：按 F9 停止，再按 F8 依目前視窗重新辨識。
- **回報問題**：在 [GitHub Issues](https://github.com/MinamiChiwa/mabinogi-mobile-color-studio/issues) 附上本次紀錄，不必為回報重複使用染色劑。

資料通常存在程式旁的 `data`；目錄無法寫入時會使用 `%LOCALAPPDATA%\MabinogiMobileColorStudio\data`，必要時使用暫存目錄。手動搬移時請複製實際使用的資料目錄。
