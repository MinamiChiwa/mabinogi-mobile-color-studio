## 使用

目前正式版本為 `ColorStudio-v0.3.6`。請解壓縮完整發布包後執行 `ColorStudio.exe`，並保留同一目錄內的 `_internal` 資料夾。發布包包含 OCR 與英文辨識資料，不必安裝 Python 或另行安裝 Tesseract。升級時請先關閉舊程式，並解壓縮至獨立資料夾。

1. 在遊戲中將視窗設為 1280 × 960。程式預設啟用三個區域；不需要比對的區域可手動關閉。輸入 HEX、使用選色器或螢幕吸管，也可填寫替代顏色。
2. 每個區域可個別選擇精準 HEX 或相似顏色。精準模式要求 HEX 完全一致，相似模式依設定的色差範圍比對。方案同時考量各區域色差與落點附近的顏色變化，優先選擇符合全部設定、顏色穩定的組合。需要折衷時，先兼顧各區域的接近程度，整體品質相同時優先精準命中，避免為了一個精準區域而使其他區域明顯偏色。浮窗會標明實測未達標或色系偏離。
3. 相似區域依各區設定的 ΔE 容差搜尋。若沒有候選符合全部設定，程式會從可執行候選中選擇兼顧各區域色差與落點顏色變化的折衷方案。
4. 選擇遊戲視窗後點擊開始或按 **F8**。浮窗出現後，請手動進入遊戲染色倒數介面。僅啟用一個區域時，程式直接探索目前畫板，完成尋色後即可手動調整；啟用多個區域時，程式先拼接本局大圖，再搜尋、定位並複核遊戲 HEX。按 **F9** 可隨時停止。

**單色模式提示：**精準模式以辨識色板後的約 60 秒為主要搜尋階段，優先尋找完全一致的 HEX；未命中時嘗試定位已實測的最佳折衷結果，收尾可能稍多幾秒。相似模式連續兩幀達到設定容差後停止。搜尋使用有限平移與少量實測縮放；縮放反應無法確認時停止該路線，不反覆觸及倍率極限。剩餘遊戲時間可用於手動調整。若最終未達標，浮窗會明確標示「未命中目標・折衷方案」，表示目前顯示的是本局已複核的最接近結果，並非工具故障。

自動偵測相容標題中的空格差異，也會辨識遊戲處理程序名稱。出現多個候選時請手動選擇；所選視窗關閉後須重新選擇。支援無邊框全螢幕，正式尋色期間請保持遊戲在前景且視窗尺寸不變。

程式完成定位後會顯示遊戲內 HEX，請在遊戲中確認結果後手動套用染色。

僅啟用一個區域時，精準與相似模式皆略過整板拼接，使用平移與少量縮放直接探索色板；啟用多個區域時，使用本局拼圖搜尋，並依候選計算旋轉、縮放與平移。自動操作期間請勿移動滑鼠。執行期間若視窗位置或大小改變，尋色會停止，須重新按 F8。

介面右上角可選擇簡體中文、繁體中文或 English；主視窗、浮窗及已開啟的資訊視窗會即時切換，不必重啟。主介面會依視窗寬度改用三欄、兩欄或單欄；問號按鈕開啟教學，支持作者視窗提供愛發電與 Patreon。

## 預覽與記錄

- 主介面顯示有序色塊概覽，點選開啟完整允許顏色集合。
- 大圖使用 ＋／－ 縮放、拖曳瀏覽及游標停留檢視 HEX，不需要翻頁。
- 尋色記錄儲存最近 50 次結果，包含三色組合、各區 ΔE、最大和平均色差。
- 正式尋色流程會複核遊戲 HEX，並在浮窗中顯示結果。精準模式的色差滑條不可用。
- 本機配置、記錄及診斷截圖預設存放在程式旁的 `data` 資料夾。若安裝目錄不可寫入，程式會改用 `%LOCALAPPDATA%\MabinogiMobileColorStudio\data`；該位置也不可用時才使用系統暫存目錄。
- 診斷記錄會在背景自動清理，保留最近 3 次記錄；進行中或最近 5 分鐘內有更新的記錄會暫時保留。清理不設定總容量上限。系統暫存目錄中的資料可能遭系統清除。

## 開發

Windows 10/11，Python 3.12。原始碼位於 `work/studio`。

```powershell
python -m pip install -r requirements-build.txt
python work/studio/app.py
python run_tests.py
```

預設執行目前生產迴歸；完整原始碼檢查使用 `python run_tests.py --profile all`。實驗診斷、舊流程與私有素材測試分組執行，詳見 [測試範圍](work/studio/TESTING.md)。

原始碼執行與構建還需要安裝 Tesseract OCR（含 `eng.traineddata`）。預設位置為 `C:/Program Files/Tesseract-OCR`；構建時可設定 `TESSERACT_HOME`。

```powershell
python work/studio/build_release.py
```

產物在 `outputs/release/ColorStudio`。現有釋出目錄的個人資料會備份到 `work/studio/release-test-data`，不會提交到倉庫。遊戲實拍迴歸素材屬於本機測試資料，未隨倉庫分發；缺少這些素材時相關測試會顯示跳過。

## 驗證範圍

限時搜尋不保證精準命中、符合所有容差或取得全域最佳組合。版面計算矩陣涵蓋 1024×768、1920×1080、3840×2160、5120×2880 及 100%、125%、150%、200%、250% DPI；另有實體像素座標換算與負座標多螢幕測試。這些檢查不代表所有 4K、多螢幕及混合 DPI 設定均已完成實機遊戲驗證。

簡體中文、繁體中文與 English 的主視窗、浮窗、教學、支援視窗及執行狀態都能即時切換。OCR 固定使用 `eng` 資料，不受介面語言影響；程式會處理 Windows 本機路徑的非 UTF-8 輸出。工具視窗依顯示器工作區計算尺寸；4K 螢幕亦應將遊戲設為 1280 × 960 視窗模式，不必修改桌面解析度。

啟動後請保持遊戲在前景，並在染色倒數介面等待程式完成。需要中止時按 F9；若遊戲視窗位置或大小發生變更，請停止後重新開始。若無法自動切回遊戲，請手動點擊遊戲視窗即可繼續等待辨識。底部顯示快捷鍵註冊狀態；衝突時請關閉其他工具副本或使用按鈕。

主介面的顏色卡片維持固定尺寸，視窗寬度變更時依欄數重新排列。啟用卡片有青色邊框與底色，停用卡片顯示「未啟用」。浮窗可移動、收合及調整透明度，並顯示目前階段與經過時間；長內容可捲動，標題與 F9 停止按鈕保持可見。顏色數值支援點選或拖曳調整。定位或讀色暫未完成時，浮窗會顯示復原狀態及目前可讀取的結果。

截圖顏色預測仍可能與遊戲實際 HEX 有偏差。工具在移動完成後讀取並顯示遊戲 HEX，最終套用須在遊戲內手動完成。目前驗證範圍、結果及限制見 [驗證報告](work/studio/VERIFICATION.md)。版本更新內容集中於發布頁。

原始碼環境可透過 `run_preflight.bat` 進行唯讀預檢，檢查遊戲截圖、實際用戶端區域尺寸與 DPI；保護條件使用模擬檢查，不傳送遊戲輸入。該腳本需要原始碼環境，並非正式版壓縮包的必要步驟。
