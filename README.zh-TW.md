## 使用

從 Releases 下載完整壓縮包，解壓後執行 `ColorStudio.exe`，保留旁邊的 `_internal` 資料夾。

1. 在遊戲中將視窗設為 1280 × 960。程式預設啟用三個區域；不需要比對的區域可手動關閉。輸入 HEX、使用選色器或螢幕吸管，也可填寫替代顏色。
2. 每個區域可個別選擇精準 HEX 或相似顏色。即使只將一個或兩個區域設為精準 HEX，也優先於其餘相似區域：先比較精準命中區域數；命中數相同時，再比較所有啟用區域的最大色差和平均色差。精準區域必須完全命中 HEX。
3. 相似區域依您設定的 ΔE 容差搜尋，沒有固定 ΔE 8 上限。若沒有候選符合全部設定，程式仍會依相同優先順序定位最接近且可執行的折衷方案。
4. 選擇遊戲視窗後點擊開始或按 **F8**。浮窗出現後，請手動進入遊戲染色倒數介面。程式會先拼接本局大圖，再搜尋、定位並複核遊戲 HEX；按 **F9** 可隨時停止。

自動偵測相容標題中的空格差異，也會辨識遊戲處理程序名稱。出現多個候選時請手動選擇；所選視窗關閉後須重新選擇。支援無邊框全螢幕，正式尋色期間請保持遊戲在前景且視窗尺寸不變。

六十秒是效能參考，不是硬性截止；只要遊戲倒數允許，程式就會繼續完成正常流程。截圖預測並非最終結果，最後以遊戲 HEX 複核為準；是否套用染色由您決定。

精準模式遇到接近顏色會以該色塊為縮放中心分批放大。旋轉以右鍵按下處為圓心，縮放以滑鼠位置為支點。視窗位置或大小在執行期間改變會停止尋色，需要重新按 F8。

介面右上角可選擇簡體中文、繁體中文或 English；主視窗、浮窗及已開啟的資訊視窗會即時切換，不必重啟。主介面會依視窗寬度改用三欄、兩欄或單欄；問號按鈕開啟教學，支持作者視窗提供愛發電與 Patreon。

## 預覽與記錄

- 主介面顯示有序色塊概覽，點選開啟完整允許顏色集合。
- 大圖使用 ＋／－ 縮放、拖曳瀏覽及游標停留檢視 HEX，不需要翻頁。
- 尋色記錄儲存最近 50 次結果，包含三色組合、各區 ΔE、最大和平均色差。
- 自動複核套用預設關閉。精準模式的色差滑條不可用。
- 本機配置、記錄及診斷截圖存放在程式旁的 `data` 資料夾。
- 程式會保留最近 20 次尋色記錄；超過 30 天或總大小超過 512 MiB 的舊工作階段，會在開始新一局前自動清理；進行中及最近 5 分鐘內的工作階段不會被清理。

## 開發

Windows 10/11，Python 3.12。原始碼位於 `work/studio`。

```powershell
python -m pip install -r requirements-build.txt
python work/studio/app.py
python -m unittest discover -s work/studio -p "test_*.py"
```

原始碼執行與構建還需要安裝 Tesseract OCR（含 `eng.traineddata`）。預設位置為 `C:/Program Files/Tesseract-OCR`；構建時可設定 `TESSERACT_HOME`。

```powershell
python work/studio/build_release.py
```

產物在 `outputs/release/ColorStudio`。現有釋出目錄的個人資料會備份到 `work/studio/release-test-data`，不會提交到倉庫。遊戲實拍迴歸素材屬於本機測試資料，未隨倉庫分發；缺少這些素材時相關測試會顯示跳過。

## 驗證範圍

有限時間內的搜尋不保證每次找到精準顏色或全域性最優組合；當前實機驗證不覆蓋所有 DPI 與顯示器組合。

啟動後持續等待色板與倒數計時，按 F9 可取消。六十秒是效能參考，不是正常使用的硬截止；即使建圖和搜尋超過六十秒，腳本仍會繼續完成流程。只有遊戲 OCR 倒數實際到達安全截止、F9、失焦、視窗變更或辨識失效時才會停止相關輸入。若無法自動切回遊戲，請手動點擊遊戲視窗，無須重複啟動。底部顯示快捷鍵註冊狀態；衝突時請關閉其他工具副本或使用按鈕。

主介面會依視窗寬度在三欄、兩欄與單欄間切換，拖曳調整時會延遲重排以減少卡頓。啟用卡片有青色邊框與底色，停用卡片顯示「未啟用」。浮窗可移動、收合及調整透明度，並顯示即時進度。所有工具介面控制項均不接受滾輪輸入；數值以點擊或拖曳調整。等待期間暫時切換視窗後可返回遊戲繼續辨識；中斷或錯誤會彈窗提示。

目前版本的截圖顏色預測仍可能與遊戲實際 HEX 有偏差。工具會在移動完成後讀取遊戲 HEX；若複核未達到目標，會保留結果供您判斷，不會自動套用。
